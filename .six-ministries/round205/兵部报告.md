## 任务概述
增强nas-os项目的FRP内网穿透模块，添加免费公共服务器节点支持和一键连接API。

---

## 新增代码文件

### 1. `internal/connect/frp/free_nodes.go`
**功能**：免费公共服务器节点配置

**新增结构**：
- `NodeRegion` - 节点区域枚举（cn/us/eu）
- `FreeNode` - 免费节点信息结构
- `FreeNodeConfig` - 免费节点配置管理器
- `QuickConnectConfig` - 一键连接配置
- `QuickConnectResult` - 一键连接结果

**默认节点列表**（参考飞牛FN Connect）：
| ID | 名称 | 区域 | 地址 |
|---|---|---|---|
| cn-connect-1 | FN Connect CN-1 | cn | connect.fnos.cn:7000 |
| cn-tunnel-1 | FN Tunnel CN-1 | cn | tunnel.fnos.cn:7000 |
| us-connect-1 | FN Connect US-1 | us | connect.fnos.us:7000 |
| eu-connect-1 | FN Connect EU-1 | eu | connect.fnos.eu:7000 |

**核心方法**：
- `GetNode(id)` - 获取指定节点
- `GetAllNodes()` - 获取所有节点
- `GetNodesByRegion(region)` - 按区域获取节点
- `GetBestNode(region)` - 获取最优节点（按优先级）
- `AddNode(node)` - 添加自定义节点
- `RemoveNode(id)` - 移除节点
- `UpdateNodeStatus(id, online, latency)` - 更新节点状态
- `NodeToClientConfig(node)` - 节点转客户端配置

### 2. `internal/connect/frp/manager.go`
**功能**：FRP客户端管理器 - 一键连接和实时监控

**新增结构**：
- `ClientManager` - 客户端管理器
- `ClientStatusInfo` - 客户端状态信息
- `ClientEvent` - 客户端事件
- `NodeHealthResult` - 节点健康检查结果

**核心API**：

#### 一键连接API
- `QuickConnect(config)` - 一键连接免费节点
  - 自动选择最优节点（默认中国节点）
  - 支持指定节点ID或区域
  - 自动创建隧道
  - 返回公网访问URL

#### 连接管理API
- `Disconnect(clientID)` - 断开指定客户端
- `DisconnectAll()` - 断开所有客户端
- `GetClient(clientID)` - 获取客户端实例
- `GetAllClients()` - 获取所有客户端

#### 实时监控API
- `GetClientStatus(clientID)` - 获取单个客户端状态
- `GetAllClientStatus()` - 获取所有客户端状态（实时）
- `Events()` - 返回事件通道（连接/断开/隧道变化）
- `HealthCheck(ctx)` - 健康检查所有节点

#### 状态信息包含
- 连接状态（connected/disconnected/connecting/error）
- 连接时间和运行时长
- 流量统计（发送/接收字节数）
- 隧道状态列表
- 最后更新时间

## 使用示例

```go
// 创建管理器
mgr := frp.NewClientManager(logger)

// 一键连接（自动选择最优中国节点）
result, err := mgr.QuickConnect(&frp.QuickConnectConfig{
    LocalPort: 8080,
})
// result.PublicURL: "connect.fnos.cn:xxxxx"

// 指定区域连接（美国节点）
result, err := mgr.QuickConnect(&frp.QuickConnectConfig{
    Region:    frp.RegionUS,
    LocalPort: 8080,
})

// 获取所有客户端状态
statuses := mgr.GetAllClientStatus()

// 监听事件
for event := range mgr.Events() {
    // 处理连接/断开事件
}

// 健康检查所有节点
results := mgr.HealthCheck(ctx)
```
