## 三、Registry Mirrors 设计方案

### 3.1 配置文件结构

**存储路径**: `/etc/nas-os/docker-registry.json`

```json
{
  "mirrors": [
    {
      "url": "https://mirror1.example.com",
      "priority": 1,
      "enabled": true,
      "description": "阿里云镜像源"
    },
    {
      "url": "https://mirror2.example.com",
      "priority": 2,
      "enabled": true,
      "description": "腾讯云镜像源"
    }
  ],
  "insecureRegistries": [],
  "defaultMirror": "https://mirror1.example.com",
  "updatedAt": "2026-04-09T10:00:00Z"
}
```

### 3.2 API端点设计

**路径**: `/api/v1/system/docker/registry-mirrors`

| 方法 | 功能 | 权限 |
|------|------|------|
| GET | 获取当前镜像源配置 | admin |
| PUT | 更新镜像源配置 | admin |

**GET 响应示例**:
```json
{
  "code": 200,
  "data": {
    "mirrors": [...],
    "effectiveConfig": "# Docker daemon.json 内容",
    "status": "applied"
  }
}
```

**PUT 请求示例**:
```json
{
  "mirrors": [
    {"url": "https://new-mirror.com", "priority": 1, "enabled": true}
  ],
  "restartDocker": true
}
```

### 3.3 实现要点

```go
// internal/docker/registry_mirror.go

type RegistryMirror struct {
    URL         string `json:"url" binding:"required"`
    Priority    int    `json:"priority"`
    Enabled     bool   `json:"enabled"`
    Description string `json:"description"`
}

type RegistryConfig struct {
    Mirrors           []RegistryMirror `json:"mirrors"`
    InsecureRegistries []string        `json:"insecureRegistries"`
    DefaultMirror     string           `json:"defaultMirror"`
}

// 核心逻辑:
// 1. 配置存储在 /etc/nas-os/docker-registry.json
// 2. 应用时生成 /etc/docker/daemon.json
// 3. 支持 restartDocker 参数自动重启服务
// 4. 按priority排序，enabled=true的镜像参与fallback
```

### 3.4 Docker daemon.json 生成

```go
func generateDaemonJSON(config *RegistryConfig) ([]byte, error) {
    daemon := map[string]interface{}{
        "registry-mirrors": config.GetEnabledMirrors(),
    }
    
    if len(config.InsecureRegistries) > 0 {
        daemon["insecure-registries"] = config.InsecureRegistries
    }
    
    return json.MarshalIndent(daemon, "", "  ")
}
```
