## 一、竞品成本对比分析

### 1.1 群晖 Synology DSM

#### 硬件成本（典型配置）
| 型号系列 | 定位 | 4盘位入门价 | 8盘位中端价 | 高端企业价 |
|---------|------|------------|------------|-----------|
| J Series | 入门级 | ¥1,500-2,500 | - | - |
| Value Series | 家用 | ¥3,000-5,000 | ¥5,000-8,000 | - |
| Plus Series | 进阶 | ¥5,000-10,000 | ¥10,000-20,000 | - |
| XS+/XS Series | 企业 | - | ¥15,000-30,000 | ¥50,000+ |
| FS Series | 全闪存 | - | - | ¥100,000+ |

**特点：**
- 硬件捆绑销售，软件免费
- 硬件溢价明显（约 30-50% vs 自攒）
- 扩展性受限（型号固定）
- 品牌溢价 + 售后服务成本

#### 软件成本
- DSM 系统：免费（绑定硬件）
- 套件商店：大部分免费
- 授权限制：硬件绑定，无独立软件授权
- 升级服务：免费（限硬件生命周期）

#### 隐性成本
| 项目 | 成本估算 |
|------|---------|
| 硬件折旧 | 5年周期，年成本 = 硬件价/5 |
| 硬盘更换 | 硬盘成本（通用） |
| 扩展限制 | 需整机更换才能扩容 |
| 品牌溢价 | 约硬件成本的 30-40% |

| Mini 系列 | ¥8,000-12,000 | 官方小型设备 |

- TrueNAS Enterprise：付费版（高级支持）
- 无授权限制
- 无硬件绑定

#### TrueNAS 开源优势总结
1. **零软件授权费** - 完全开源免费
2. **硬件自由度** - 任意 x86 硬件兼容
3. **扩展灵活** - 无需品牌锁定
4. **ZFS 高级特性** - 企业级存储功能免费
5. **社区支持** - 免费文档和论坛

#### 预测能力
| 功能 | 实现状态 | 说明 |
|------|---------|------|
| 线性预测 | ✅ 已实现 | 日增长量推算 |
| 指数预测 | ✅ 已实现 | 复合增长率模型 |
| 对数预测 | ✅ 已实现 | 增长趋缓模型 |
| 置信区间 | ✅ 已实现 | ±10% 误差范围 |
| 里程碑预测 | ✅ 已实现 | 70%/80%/90%/95% 预警线 |
| 扩容建议 | ✅ 已实现 | 自动计算建议扩容量 |

### 3.2 容量预测算法

#### 线性增长模型
```
预测容量 = 当前容量 + 日增长量 × 天数
日增长量 = (最新容量 - 7天前容量) / 7
```

#### 指数增长模型
```
预测容量 = 当前容量 × (1 + 日增长率)^天数
月增长率 → 日增长率：日率 = 月率 / 30
```

#### 复合月增长率计算
```
CAGR = (终值/初值)^(1/月数) - 1
```

### 3.3 预测配置参数

```go
type CapacityPlanningConfig struct {
    AlertThreshold      float64 // 预警阈值 70%
    CriticalThreshold   float64 // 紧急阈值 85%
    ForecastDays        int     // 预测天数 90天
    GrowthModel         GrowthModel // 增长模型类型
    ExpansionLeadTime   int     // 扩容提前期 30天
    SafetyBuffer        float64 // 安全缓冲 20%
}
```

### 3.4 输出报告结构

```
CapacityPlanningReport:
  - ID/Name/VolumeName/Period
  - Current: 当前容量状态
  - Forecasts: 90天预测数据点
  - Milestones: 容量里程碑（70%/80%/90%/95%）
  - Recommendations: 扩容/清理/优化建议
  - Summary: 汇总（增长率、满容量日期、紧急程度）
```

## 四、运营成本模型

### 4.1 成本计算框架（已实现）

见 `internal/reports/storage_cost_test.go`：

```go
type StorageCostConfig struct {
    CostPerGBMonthly        float64 // 0.5元/GB/月
    CostPerIOPSMonthly      float64 // 0.01元/1000 IOPS/月
    CostPerBandwidthMonthly float64 // 1元/Mbps/月
    ElectricityCostPerKWh   float64 // 0.6元/kWh
    DevicePowerWatts        float64 // 100W
    OpsCostMonthly          float64 // 500元/月（运维）
    DepreciationYears       int     // 5年折旧
    HardwareCost            float64 // 硬件成本
}
```

### 4.2 成本构成

| 成本类型 | 计算公式 |
|---------|---------|
| 容量成本 | 已用GB × 单位GB月费 |
| 性能成本 | IOPS × 单位IOPS月费 |
| 带宽成本 | Mbps × 单位带宽月费 |
| 电力成本 | 功率W × 小时数 × 电价 |
| 折旧成本 | 硬件成本 / 折旧年限 |
| 运维成本 | 固定月费 |
