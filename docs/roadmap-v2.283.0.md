# nas-os v2.283.0 路线图

> 版本周期: 2026-03-26 ~ 2026-03-31
> 负责部门: 吏部(规划) + 六部协同

---

## 🎯 版本目标

本版本聚焦三大核心功能：私有云AI服务完善、勒索软件防护启动、内网穿透功能测试。

---

## 📋 功能模块

### 1. 私有云AI服务完善 ☁️

**负责部门**: 兵部(开发) + 刑部(安全)

**功能要点**:
- [ ] OpenAI兼容API服务端点
- [ ] 敏感数据本地脱敏处理
- [ ] 多AI模型切换支持
- [ ] API密钥管理界面
- [ ] 调用日志与审计

**技术方案**:
- 后端: Go + OpenAI SDK
- 脱敏: 正则匹配 + 本地处理
- 存储: 加密配置存储

**参考竞品**:
- 群晖DSM AI Console - 数据遮罩功能
- 本地处理敏感信息后再发送云端AI

**验收标准**:
- [ ] 支持至少3个主流AI模型接入
- [ ] 敏感数据识别准确率 > 95%
- [ ] API响应延迟 < 500ms

---

### 2. 勒索软件检测模块 🛡️

**负责部门**: 刑部(安全) + 兵部(实现)

**功能要点**:
- [ ] 文件异常行为监控
  - 大量文件快速加密检测
  - 可疑进程行为分析
  - 文件扩展名批量变更检测
- [ ] 快照自动保护
  - 检测到攻击自动创建快照
  - 关键数据快照锁定
- [ ] 告警通知
  - 多通道告警（邮件/Webhook/企业微信）
  - 攻击行为可视化报告

**技术方案**:
- 监控: inotify + 行为分析引擎
- 快照: btrfs snapshot + 不可变标记
- 告警: 复用现有告警系统

**参考竞品**:
- TrueNAS 不可变快照
- 群晖 Snapshot Replication

**验收标准**:
- [ ] 勒索软件行为检测率 > 90%
- [ ] 响应时间 < 5秒
- [ ] 误报率 < 1%

---

### 3. 内网穿透功能测试 🌐

**负责部门**: 工部(运维) + 兵部(开发)

**功能要点**:
- [ ] FRP服务端部署测试
- [ ] WireGuard隧道验证
- [ ] 带宽与延迟性能测试
- [ ] 安全性评估
  - 加密强度验证
  - 访问控制测试
- [ ] 多场景兼容性测试
  - NAT穿透成功率
  - 移动网络适配

**技术方案**:
- FRP: 中转服务器部署
- WireGuard: P2P直连隧道
- 测试: 自动化测试脚本

**参考竞品**:
- 飞牛FN Connect稳定服务
- 群晖QuickConnect

**验收标准**:
- [ ] NAT穿透成功率 > 85%
- [ ] 延迟 < 100ms（国内）
- [ ] 安全审计通过
