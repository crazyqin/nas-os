# NAS-OS 竞品分析报告

**更新日期**: 2026-07-16  
**版本**: v3.24.3

## 概述

本文档对比分析 NAS-OS 与 Synology DSM、TrueNAS、飞牛 fnOS、QNAP QuTS hero 等主流 NAS 平台的公开能力，聚焦本地 AI、存储效率、权限安全、文件共享、媒体体验和企业运维。NAS-OS 的定位是开源、可自托管、兼顾家庭与中小企业的 NAS 系统。

**架构说明（阅读对标表前请先了解）**：生产生命周期 **Core 仅** `identity` / `storage` / `network` / `sharing` / `system`。可选产品能力在 `internal/extensions/` 与 recommended 产品面，且 **默认不加载**（主配置 `packages.enabled` / `packages.recommended_system`；`modules.*` 已弃用兼容）。大量实验与对标增强实现在 `internal/lab/`，**不进入默认 `nasd` 热路径**。详见 [ARCHITECTURE.md](ARCHITECTURE.md)。

### v3.14.0 备份健康顾问对标补充（历史能力）

- 群晖 Active Backup 强调集中保护 PC/Mac、裸机恢复、计划模板、增量备份与全局去重；本轮将这些能力抽象成终端保护率、失败任务修复、增量/去重节省空间建议。
- TrueNAS 的快照、校验、复制和不可变恢复点适合作为数据韧性基线；本轮在关键共享、勒索告警、快照数量、不可变快照和异地副本信号上生成高优先级动作。
- 飞牛 fnOS 的价值在于家庭用户低门槛体验；本轮把恢复演练、USB/ISO 恢复介质和 RPO/RTO 预估组织成向导可消费的下一步建议。

| **存储效率** | 去重、压缩、冷热分层、容量优化方向 | ✅ 存储效率统计、Smart Dedup、生命周期策略、成本/ROI 分析 |
| **RBAC / 企业权限** | 细粒度角色、域控和审计 | ✅ RBAC/MFA/审计/设备信任/SSO 协议扩展 |

### DSM 优势
- 商业生态成熟，套件联动完整。
- 硬件、系统、企业支持一体化。
- 对办公室/企业协作场景打磨较深。

### NAS-OS 差异化
- 开源免费，无硬件绑定。
- 本地 LLM、CLIP 以文搜图、MCP 和语义搜索治理组合更开放。
- WORM/不可变审计、气隙备份、多云挂载、成本/ROI 分析覆盖更广。

## v3.12.0 对标结论

| 方向 | 本轮公开竞品信号 | NAS-OS 用户价值表达 |
|------|------------------|----------------------|

| 数据保护 | TrueNAS 的优势在 ZFS 快照、scrub、数据完整性和容量规划 | NAS-OS 在建议层突出恢复校验、不可变快照、scrub、生命周期分层和扩容规划，把可靠性动作前置 |

NAS-OS 已在 TrueNAS 26 的 WebShare/TrueSearch/LXC/FEC/重启原因方向、DSM 7.4 的本地 AI/存储效率/RBAC 方向、fnOS 的媒体与远程访问方向、QNAP h6.0 的不可变快照/FileTiers/passkeys 方向形成公开对标。v3.12.0 的文档重点进一步从“功能堆叠”转向“发现-整理-治理”：围绕 **体验顾问、智能文件夹、成本容量治理、本地 AI 治理、存储效率中心、不可变数据保护、媒体与远程访问、现代身份安全** 组织产品叙事。

## v3.15.0 存储效率与合规审计对标补充

### 快照调度器
- TrueNAS 定时快照（periodic snapshots）支持自定义频率和保留数；本轮实现了小时/日/周/月级快照策略推荐，并增加了不可变快照和异地复制建议。
- Synology 快照管理器（Snapshot Manager）提供可视化调度；本轮将调度策略抽象为 Policy 结构，支持自动推荐关键共享的快照参数。
- 飞牛 fnOS 的时间线文件保护提供低门槛回溯；本轮通过 SuggestPolicy 自动生成适合家庭和中小企业的默认策略。

### 存储成本预测器
- Synology 存储分析器提供容量趋势和成本仪表盘；本轮实现了月度成本预测、预算超支预警、分层/去重/压缩节省估算。
- TrueNAS 容量规划依赖 ZFS 属性；本轮将成本预测抽象为独立模块，支持历史趋势输入和预算比较。

### 系统公告板
