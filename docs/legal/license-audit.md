## 一、项目概况

NAS-OS 是基于 Go 语言开发的家用 NAS 系统，采用 MIT 许可证发布。项目共有 **268 个依赖包**，其中直接依赖 40+ 个核心库。

## 五、合规建议

### 5.1 必要措施

1. **创建 NOTICE 文件**
   ```bash
   # 在项目根目录创建 NOTICE 文件
   # 包含 Apache-2.0 依赖的版权声明
   ```

2. **保留版权声明**
   - 所有 MIT/Apache/BSD 依赖需保留原始 LICENSE 文件或版权声明

3. **声明 SQLite 许可证**
   - `modernc.org/sqlite` 使用 zlib/libpng 许可证
   - 需在分发时声明

### 5.2 建议措施

1. **安装 go-licenses 工具**
   ```bash
   go install github.com/google/go-licenses@latest
   go-licenses save ./cmd/nasd --save_path third_party
   ```

2. **定期扫描**
   - 每次依赖更新后重新扫描
   - 检查新增依赖的许可证

3. **使用固定版本**
   - 避免 v0.0.0-xxxxx 格式的伪版本
   - 使用明确版本号便于追溯

### 5.3 分发合规清单

分发 NAS-OS 二进制/源码时需：

1. ✅ 包含本项目 LICENSE 文件 (MIT)
2. ✅ 包含 NOTICE 文件 (声明第三方版权)
3. ✅ 源码分发时包含第三方 LICENSE 文件
4. ✅ 二进制分发时在文档中声明依赖版权

```

Apache-2.0 ← 可与 MIT、BSD 兼容
```
