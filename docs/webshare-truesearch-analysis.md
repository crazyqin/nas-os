# TrueSearch 竞品分析

## TrueNAS TrueSearch 设计参考

### 功能特性

TrueNAS 26 引入的 TrueSearch 全文搜索能力：

1. **全文内容索引**
   - 支持文件内容全文检索
   - 支持 PDF、Office 文档、文本文件等
   - 支持正则表达式搜索

2. **多层次索引**
   - 文件名索引（即时更新）
   - 文件内容索引（批量/增量更新）
   - 文件类型索引（按扩展名分类）
   - 元数据索引（创建时间、大小、权限等）

3. **安全边界**
   - 加密数据集不索引（内容不可读）
   - 加密数据集仅索引文件名（若允许）
   - 权限过滤（仅返回用户可访问的文件）
   - 敏感文件排除配置

4. **性能优化**
   - 批量索引（后台异步）
   - 增量更新（检测文件变更）
   - 索引缓存（Bleve/SQLite）
   - 分页查询（避免大结果集）

5. **搜索体验**
   - 实时搜索建议
   - 高亮匹配结果
   - 文件预览
   - 搜索历史

### 关键设计决策

1. **索引策略**
   - 文件名索引：实时更新（文件创建/删除/重命名）
   - 内容索引：后台批量 + 增量检测（修改时间比对）
   - 最大文件限制：10MB（避免内存溢出）
   - 文本类型检测：扩展名 + MIME 类型

2. **加密数据集处理**
   - ZFS 加密数据集检测（zfs get encryption）
   - 加密状态标记（isEncrypted 字段）
   - 跳过内容索引，仅索引文件名（配置可选）
   - 加密密钥未加载时完全不索引

3. **权限控制**
   - 遵循文件系统权限（POSIX ACL）
   - 用户级搜索结果过滤
   - 管理员可见所有文件
   - 搜索 API 认证

4. **中文支持**
   - CJK 分词器（Bleve 内置）
   - 关键词提取（高频词）
   - 语言检测（中英文混合）

### 对比与改进

| 特性 | TrueNAS TrueSearch | nas-os WebShare Search | 改进点 |
|------|---------------------|------------------------|--------|
| 全文索引 | Bleve | Bleve + Memory | 双引擎，灵活性更高 |
| 加密检测 | ZFS encryption | 待实现 | 需添加加密检测 |
| 权限过滤 | POSIX ACL | 待完善 | 需加强权限控制 |
| 中文分词 | CJK | CJK | 已实现 |
| 搜索建议 | 有 | 有 | 已实现 |
| 文件预览 | 有 | 有 | 已实现 |
| 搜索历史 | 有 | 无 | 待实现 |
| 正则搜索 | 有 | 无 | 待实现 |

### 实现优先级

P0（必须）:
- 加密数据集检测与排除
- 统一搜索 API
- 权限过滤

P1（重要）:
- 搜索历史
- 正则表达式搜索
- 索引性能监控

P2（优化）:
- 搜索结果缓存
- 智能搜索建议
- 文件内容预览增强
