## TrueNAS Scale 25.10 深度分析

### 核心新特性

#### 1. SMB Spotlight 集成
- **功能**: macOS Spotlight 搜索兼容
- **技术**: Tracker SPARQL + SMB协议扩展
- **价值**: Mac用户无缝搜索NAS文件
- **nas-os状态**: ✅ 已实现 (v2.403.0)

#### 2. LXC容器支持 (Sandboxes)
- **功能**: 轻量级Linux容器
- **技术**: LXC/LXD + 安全隔离
- **价值**: 比Docker更接近主机性能
- **nas-os状态**: 📋 需开发

#### 3. SMB Stateful Failover
- **功能**: SMB会话保持
- **技术**: CTDB + 集群心跳
- **价值**: 零中断故障转移
- **nas-os状态**: 📋 需开发

#### 4. RAIDZ Expansion
- **功能**: 单盘在线扩容RAIDZ
- **技术**: OpenZFS 2.3特性
- **价值**: 灵活扩容无需重建
- **nas-os状态**: ✅ API完成，UI待开发
