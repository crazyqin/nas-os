# v2.385.0 新功能说明

## 文件活动监控

对标群晖Active Insight，实现实时文件操作追踪能力。

### 功能特性
- 实时监控文件创建、修改、删除、访问事件
- 支持按路径过滤监控范围
- 事件记录持久化存储
- 异常行为检测与告警

### API端点
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/audit/file-activity | 获取文件活动记录 |
| POST | /api/v1/audit/file-activity/watch | 添加监控路径 |
| DELETE | /api/v1/audit/file-activity/watch/:id | 移除监控路径 |
| GET | /api/v1/audit/file-activity/stats | 获取活动统计 |

---

## 自定义事件规则

用户可自定义监控规则，灵活配置告警触发条件。

### 功能特性
- 支持路径正则匹配
- 事件类型筛选（创建/修改/删除/访问）
- 告警阈值配置
- 多通道通知支持

### API端点
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/automation/rules | 获取事件规则列表 |
| POST | /api/v1/automation/rules | 创建事件规则 |
| PUT | /api/v1/automation/rules/:id | 更新规则配置 |
| DELETE | /api/v1/automation/rules/:id | 删除规则 |

---

## Fleet多节点监控增强

多节点集中监控能力增强，支持跨节点告警联动。

### 功能特性
- 多节点健康状态聚合展示
- 跨节点资源利用率统计
- 告警规则跨节点联动
- Dashboard集中管理视图

### API端点
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/cms/fleet/health | 获取Fleet整体健康状态 |
| GET | /api/v1/cms/fleet/nodes | 获取节点状态列表 |
| GET | /api/v1/cms/fleet/resources | 获取资源利用率汇总 |
| POST | /api/v1/cms/fleet/alerts/link | 创建跨节点告警联动 |
