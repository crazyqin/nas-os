# Passkey 无密码登录 — 用户指南

> 📅 适用于 nas-os v2.457.0 及以上版本

---

## 什么是 Passkey？

Passkey 是一种**无密码登录方式**。注册后，你只需要用设备的指纹、面部识别或 PIN 就能登录 nas-os，**再也不用记密码了**。

### Passkey 的好处

- 🔒 **更安全**：不会被钓鱼网站骗走，也不会因为密码泄露被盗号
- ⚡ **更快捷**：指纹一碰，秒级登录
- 🎯 **更省心**：不用记复杂密码，不用担心忘记密码

---

## 一、注册 Passkey

### 前提条件

- 已通过密码登录 nas-os
- 使用支持 Passkey 的浏览器（Chrome 98+、Safari 16+、Firefox 122+、Edge 98+）
- 设备有指纹/面部/PIN 认证功能

### 注册步骤

**第 1 步：进入安全设置**

登录 nas-os 后，点击右上角头像 → **用户设置** → **安全**。

> 📸 [截图占位：用户设置入口位置]

**第 2 步：打开 Passkey 管理**

在安全设置页面，找到 **「Passkey 管理」** 区域，点击 **「注册新 Passkey」**。

> 📸 [截图占位：Passkey 管理区域]

**第 3 步：填写 Passkey 名称**

输入一个容易辨识的名称，例如：

- `我的 MacBook 指纹`
- `iPhone Face ID`
- `办公室电脑 Windows Hello`

这样以后在设备列表里就能快速认出来。

> 📸 [截图占位：填写名称界面]

**第 4 步：完成设备认证**

系统会弹出你设备的认证提示：

| 设备 | 弹窗内容 |
|------|----------|
| Mac | Touch ID 指纹验证 |
| iPhone / iPad | Face ID 面部识别 |
| Windows | Windows Hello（指纹/PIN/面部） |
| Android | 指纹或设备 PIN |

按提示完成认证即可。

**第 5 步：注册成功**

看到 ✅ **「注册成功」** 提示后，新注册的 Passkey 会出现在列表中。

> 📸 [截图占位：注册成功界面]

### 💡 小贴士

- 建议在**常用设备**上都注册一个 Passkey
- 最多可以注册 **10 个** Passkey
- 如果设备丢失，可以在其他已登录设备上删除对应的 Passkey

## 二、使用 Passkey 登录

### 登录步骤

**第 1 步：打开登录页面**

在浏览器中打开 nas-os 的登录页面。

**第 2 步：输入用户名**

输入你的 nas-os 用户名（不需要输入密码）。

**第 3 步：点击「使用 Passkey 登录」**

在密码输入框下方，点击 **「使用 Passkey 登录」** 按钮。

> 📸 [截图占位：登录页面 Passkey 按钮]

**第 4 步：完成设备认证**

系统弹出设备认证提示，用指纹/面部/PIN 完成验证。

**第 5 步：登录成功** 🎉

自动跳转到控制台首页。

### 💡 小贴士

- 如果你只有一个 Passkey 设备，系统会自动选择它
- 如果有多个 Passkey，浏览器会让你选择使用哪一个
- 如果 Passkey 认证失败，你可以随时切换回密码登录

## 三、管理已注册的 Passkey

### 查看列表

进入 **用户设置** → **安全** → **Passkey 管理**，可以看到所有已注册的 Passkey。

列表中会显示：

| 信息 | 说明 |
|------|------|
| 名称 | 你注册时填的名称 |
| 设备类型 | 平台认证器（如 Touch ID）或安全密钥（如 YubiKey） |
| 注册时间 | 什么时候注册的 |
| 最近使用 | 上次使用这个 Passkey 的时间 |

### 重命名

如果你觉得 Passkey 名称不够清楚，可以随时修改：

1. 点击 Passkey 右侧的 **「⋮」** 菜单
2. 选择 **「重命名」**
3. 输入新名称，点击确认

> 📸 [截图占位：重命名操作]

### 删除

如果某个设备不再使用或丢失了：

1. 点击 Passkey 右侧的 **「⋮」** 菜单
2. 选择 **「删除」**
3. 系统会弹出确认提示：**「删除后此设备将无法使用 Passkey 登录，此操作不可撤销。确定删除？」**
4. 点击 **「确认删除」**

> ⚠️ **注意**：删除 Passkey 后，对应设备将无法通过 Passkey 登录。请确保你至少保留一种登录方式（密码或其他 Passkey）。

## 四、常见问题（FAQ）

### Q1：哪些浏览器支持 Passkey？

| 浏览器 | 是否支持 |
|--------|----------|
| Chrome 98+ | ✅ |
| Safari 16+（macOS / iOS） | ✅ |
| Firefox 122+ | ✅ |
| Edge 98+ | ✅ |
| 其他浏览器 | ⚠️ 暂不支持 |

### Q2：我的设备不支持指纹/面部识别，能用 Passkey 吗？

可以。你可以购买一个 **USB 安全密钥**（如 YubiKey），插入设备后即可作为 Passkey 使用。

### Q3：换手机后 Passkey 还能用吗？

取决于你使用的设备和同步方式：

| 设备 | 跨设备同步 |
|------|-----------|
| iPhone + Mac（iCloud Keychain） | ✅ 自动同步 |
| Android（Google Password Manager） | ✅ 自动同步 |
| Windows Hello | ❌ 仅限本机 |
| YubiKey | ✅ 插哪台用哪台 |

> 💡 建议在新设备上**重新注册一个 Passkey**，这是最可靠的方式。

### Q4：Passkey 比密码安全在哪里？

| 对比项 | 密码 | Passkey |
|--------|------|---------|
| 钓鱼攻击 | ❌ 容易被骗 | ✅ 无法被钓鱼 |
| 数据库泄露 | ❌ 密码可能被破解 | ✅ 服务器只存公钥，无法反推 |
| 暴力破解 | ❌ 可能被穷举 | ✅ 密钥空间极大，无法穷举 |
| 重放攻击 | ❌ 可能被截获重用 | ✅ 每次认证使用一次性挑战值 |

### Q5：如果我忘记了密码，又删除了所有 Passkey 怎么办？

这是最坏的情况。请联系管理员重置密码。

> 💡 **强烈建议**：始终保持密码可用，不要删除所有 Passkey 后又忘记密码。

### Q6：Passkey 会上传到 nas-os 服务器吗？

**不会**。Passkey 的私钥始终保存在你的设备本地（如 iPhone 的安全芯片、Windows 的 TPM）。nas-os 服务器只存储**公钥**，公钥无法用来冒充你登录。

### Q7：局域网内使用 Passkey 安全吗？

是的。Passkey 认证基于公钥加密，即使网络被监听，攻击者也无法获取你的私钥或伪造认证。前提是你的 nas-os 开启了 HTTPS（默认已开启）。

### Q8：可以关闭 Passkey 功能吗？

管理员可以在 **系统设置** → **安全** → **认证方式** 中禁用 Passkey 登录。禁用后，所有用户将只能使用密码登录。

## 五、故障排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 点击「使用 Passkey」没反应 | 浏览器不支持 WebAuthn | 更新浏览器或使用 Chrome/Firefox |
| 认证后提示失败 | Challenge 过期（>5分钟） | 刷新页面重试 |
| 无法注册 Passkey | 用户已有 10 个 Passkey | 删除不用的 Passkey 后重试 |
| 登录时找不到 Passkey | 该设备未注册 | 先用密码登录，然后注册 Passkey |
| iPhone 同步的 Passkey 在 Mac 上不可用 | iCloud Keychain 未开启 | 检查 iCloud 设置 → 密码与钥匙串 |
