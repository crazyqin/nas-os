# FN Connect 内网穿透用户指南

> 对标飞牛fnOS FN Connect免费内网穿透服务，nas-os提供自主可控的内网穿透方案

## 概述

FN Connect是nas-os提供的内网穿透服务，让您无需公网IP也能从外网访问家中的NAS。

### 核心优势

| 对比项 | 飞牛FN Connect | nas-os FN Connect |
|--------|---------------|-------------------|
| 依赖厂商云 | ✅ 需要 | ❌ 自托管可选 |
| 数据隐私 | 云端转发 | 本地完全自主 |
| 免费额度 | 基础免费 | 基础免费 |
| 自定义域名 | 付费订阅 | ✅ 支持 |
| 开源可控 | ❌ | ✅ 完全开源 |

## 快速开始

### 1. 开启服务

进入 **控制面板 → 网络设置 → 内网穿透**

1. 点击"启用内网穿透"
2. 选择穿透模式：
   - **自托管模式**：使用自己的服务器（推荐）
   - **云端模式**：使用官方云服务（便捷）

### 2. 配置隧道

#### 自托管模式配置

```yaml
# FRP配置示例
serverAddr: "your-server.com"
serverPort: 7000

tunnels:
  web:
    type: tcp
    localIP: "127.0.0.1"
    localPort: 80
    remotePort: 8080
  
  smb:
    type: tcp
    localIP: "127.0.0.1"
    localPort: 445
    remotePort: 4450
```

#### 云端模式配置

1. 登录nas-os官方账号
2. 自动分配穿透地址
3. 一键启用即可使用

### 3. 访问服务

穿透启用后，可通过外网地址访问：

| 服务 | 本地端口 | 穿透地址示例 |
|------|---------|-------------|
| Web管理 | 80 | `https://your-nas.fn-connect.io` |
| SMB共享 | 445 | `smb://your-nas.fn-connect.io:4450` |
| WebDAV | 5005 | `https://your-nas.fn-connect.io:5005` |

## 安全设置

### 必要措施

1. **启用HTTPS**：自动TLS证书（Let's Encrypt）
2. **设置访问密码**：至少8位强密码
3. **限制访问时段**：可选时段白名单
4. **IP白名单**：可选允许访问的IP范围

### 推荐配置

```
安全等级：高
- HTTPS：强制启用
- 访问密码：必须
- IP白名单：建议启用
- 最大连接数：100
- 连接超时：5分钟
```

## 使用场景

### 场景1：外出访问文件

```
办公室 → 手机App → 穿透隧道 → 家中NAS
```

1. 手机安装nas-os App
2. 登录账号，自动连接穿透地址
3. 浏览、下载家中文件

### 场景2：远程管理NAS

```
出差 → Web浏览器 → 穿透隧道 → NAS管理界面
```

1. 打开穿透地址
2. 输入账号密码登录
3. 完成远程管理操作

### 场景3：分享文件给朋友

```
朋友 → 临时链接 → 穿透隧道 → NAS共享文件夹
```

1. 创建临时分享链接
2. 设置有效期（如24小时）
3. 发送给朋友即可下载

## 高级配置

### 自定义域名

1. 准备自己的域名
2. 添加DNS解析到穿透服务器
3. 在FN Connect设置中绑定域名
4. 自动申请SSL证书

### 多隧道管理

支持同时开启多个隧道：

| 隧道名称 | 类型 | 本地端口 | 远程端口 | 状态 |
|---------|------|---------|---------|------|
| web | tcp | 80 | 8080 | 运行中 |
| smb | tcp | 445 | 4450 | 运行中 |
| ssh | tcp | 22 | 2200 | 已停止 |

### 带宽限制

可设置隧道带宽上限，避免影响家中网络：

```
带宽限制：10Mbps（可选）
- 峰值限制：防止占用全部带宽
- 夜间放宽：22:00-06:00不限速
```

## 故障排查

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 无法连接 | 服务器未运行 | 检查穿透服务状态 |
| 连接慢 | 带宽不足 | 调整带宽限制 |
| 频繁断开 | 网络不稳定 | 启用自动重连 |
| 认证失败 | 密码错误 | 重设访问密码 |

### 日志查看

进入 **控制面板 → 系统日志 → 内网穿透**

可查看：
- 连接记录
- 错误日志
- 流量统计
