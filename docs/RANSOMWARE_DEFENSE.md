# 勒索防护安全白皮书

## 概述

NAS-OS 勒索防护系统（Ransomware Defense）对标 TrueNAS Ransomware Defense，提供实时文件保护能力。

## 勒索威胁分析

### 常见攻击方式

| 攻击类型 | 特征 | 检测难度 |
|----------|------|----------|
| 批量加密 | 大量文件快速加密 | 低 |
| 诱饵触发 | 攻击诱饵文件 | 中 |
| 扩展名修改 | .encrypted 等后缀 | 低 |
| 文件内容修改 | 文件内容被加密覆盖 | 高 |
| 删除原文件 | 删除后创建加密版本 | 中 |

## 核心防护功能

### 1. SMB/NFS 实时监控

监控 SMB/NFS 请求，检测异常行为：

| 监控项 | 检测规则 | 响应动作 |
|--------|----------|----------|
| 写入频率 | 短时间大量写入 | 延迟写入+告警 |
| 文件扩展名 | 批量修改扩展名 | 暂停会话 |
| 文件内容 | 加密内容特征 | 阻断会话 |
| 删除操作 | 批量删除文件 | 暂停删除 |

### 2. 诱饵文件检测

在共享目录放置诱饵文件：
- 诱饵文件不显示给普通用户
- 攻击者触发诱饵即触发告警
- 自动阻断攻击者会话

配置示例：
```yaml
security:
  ransomware:
    honeypot:
      enabled: true
      files:
        - ".honeypot/important_doc.docx"
        - ".honeypot/financial.xlsx"
      alert: true
      block: true
```

### 3. 异常加密行为识别

分析文件操作模式：
- 检测加密内容特征（高熵值）
- 检测批量扩展名修改
- 检测异常读写比例

### 4. 自动响应

检测到攻击时自动响应：
- **阻断会话**: 立即终止可疑 SMB/NFS 会话
- **快照保护**: 自动创建紧急快照
- **WriteOnce**: 保护关键目录不被修改
- **告警通知**: 邮件/Webhook 通知管理员

## WriteOnce 集成

NAS-OS 独家 WriteOnce 功能提供额外保护层：

| 特性 | 说明 |
|------|------|
| WORM存储 | 写入后不可修改删除 |
| 合规保留 | 满足合规审计要求 |
| 快照保护 | 配合快照实现时间点恢复 |
| 元数据锁定 | 文件属性不可篡改 |

## 恢复流程

攻击发生后恢复步骤：

1. **确认攻击**: 查看告警详情和受影响范围
2. **隔离节点**: 暂停共享访问
3. **快照恢复**: 从最近快照恢复文件
4. **日志分析**: 分析攻击来源和路径
5. **安全加固**: 更新策略防止再次攻击

## 最佳实践

### 推荐配置

```yaml
security:
  ransomware:
    # 实时监控
    smb_monitor: true
    nfs_monitor: true
    
    # 诱饵检测
    honeypot: true
    
    # 自动响应
    auto_block: true
    auto_snapshot: true
    
    # 告警通知
    alert:
      email: admin@example.com
      webhook: https://hooks.example.com/ransomware
    
    # WriteOnce 保护目录
    protected_paths:
      - "/data/backup"
      - "/data/financial"
```
