## 三、群晖 DSM 深度分析

### 3.1 实现方式

群晖使用 **Synology Passkey**，核心特点：

1. **与 Synology Account 强制绑定**：必须登录 Synology Account 才能使用 Passkey
2. **iCloud/Google 同步**：自动将 Passkey 同步到 iCloud Keychain 或 Google Password Manager
3. **跨设备无缝体验**：iPhone 注册后，Mac 自动可用（前提是同一 iCloud 账户）

### 3.2 优势

- 生态完善，用户无需手动备份
- 跨平台（iOS/Android/Mac/Windows）体验统一
- 品牌背书，用户信任度高

### 3.3 劣势

- **数据主权问题**：依赖 Synology 云服务，用户数据需经过 Synology 服务器
- **强制账户**：必须创建 Synology Account，无法本地离线使用
- **仅支持 Synology DSM**：不适用于其他 NAS 系统

## 四、TrueNAS 26 深度分析

### 4.1 实现方式

TrueNAS 26 在 Scale 版本中通过 Web UI 支持 WebAuthn：

1. **纯 WebAuthn 实现**：符合 FIDO2 标准，无厂商绑定
2. **本地存储**：Passkey 数据存在 TrueNAS 本地数据库
3. **无云同步**：用户需自行管理多设备注册

### 4.2 优势

- 完全开源，无厂商锁定
- 支持标准漫游认证器（YubiKey 等）
- 与 TrueNAS 社区生态兼容

### 4.3 劣势

- **英文界面为主**：非中文用户友好
- **无多语言支持**：帮助文档稀缺
- **无中文教程**：对国内用户门槛高
- **无云端同步**：设备管理需手动操作

## 五、飞牛 fnOS 现状

### 5.1 当前状态

截至 2026-04-15，飞牛 fnOS 尚未正式实现 Passkey 功能。

### 5.2 分析

- fnOS 定位为家庭/个人用户，强调简单易用
- Passkey 对普通用户有学习门槛，fnOS 可能会优先实现更"傻瓜"的方式
- 预计短期内不会有 Passkey 功能

## 六、nas-os 差异化优势

### 6.1 六大差异化优势

| # | 优势点 | 详细说明 | 竞品对比 |
|---|--------|----------|----------|
| 1 | **完全自研，无厂商绑定** | WebAuthn 标准实现，不依赖任何云服务，数据主权100%属于用户 | TrueNAS 类似，但用户体验更好 |
| 2 | **中文原生体验** | 全中文界面 + 本文档中文用户指南，零门槛上手 | 群晖部分中文；TrueNAS ❌ |
| 3 | **Prometheus 监控集成** | 内置 Passkey 使用统计仪表盘，管理员可实时监控启用率、成功率、认证耗时 | **所有竞品均无此功能** |
| 4 | **灵活的备份恢复** | 支持手动导出加密备份 + 可选云端分片托管，用户自主选择 | 群晖强制同步；TrueNAS 无备份 |
| 5 | **与现有安全体系融合** | Passkey 与 nas-os 现有 RBAC、审计日志、勒索防护体系无缝集成 | 其他 NAS 无此集成深度 |
| 6 | **性能优先设计** | 目标认证耗时 P95 < 800ms，比群晖和 TrueNAS 更快 | 竞品无此性能承诺 |

### 6.2 与竞品的关键差异总结

```
群晖 DSM:     生态好，但强制 Synology Account，用户数据经过第三方
TrueNAS 26:  开源透明，但纯英文，无监控，无备份
飞牛 fnOS:   尚无 Passkey 功能
─────────────────────────────────────────────────────────
nas-os:      ✅ 完全自研  ✅ 中文体验  ✅ 监控仪表盘
             ✅ 灵活备份  ✅ 安全集成  ✅ 性能优化
```

### 6.3 市场定位

nas-os 的 Passkey 功能定位为 **「企业级安全 + 用户友好体验」**：

- 面向对**数据主权**有要求的企业/专业用户（拒绝厂商云绑定）
- 面向**追求现代体验**的个人用户（中文界面 + 快速上手）
- 面向**需要可观测性**的运维团队（Prometheus 指标开箱即用）
