// 性价比计算
func CalculateValueIndex(storage *StorageSpec) float64 {
    performanceScore := storage.SequentialRead * 0.3 +
                        storage.RandomRead * 0.5 +
                        storage.LatencyScore * 0.2
    
    totalCost := storage.PurchaseCost + 
                 storage.OperatingCost * 5
    
    return performanceScore / totalCost
}

### 5.2 数据自动分层机制

```go
// AutoTiering 自动分层策略
type AutoTiering struct {
    HotThreshold   time.Duration // 热数据判定: 24h内访问
    WarmThreshold  time.Duration // 温数据判定: 7天内访问
    ColdThreshold  time.Duration // 冷数据判定: >30天未访问
    
    PromotionRule  AccessRule    // 升层规则
    DemotionRule   AccessRule    // 降层规则
}

// 自动分层决策
func (t *AutoTiering) DecideTier(lastAccess time.Time) Tier {
    since := time.Since(lastAccess)
    
    if since < t.HotThreshold {
        return HotTier
    }
    if since < t.WarmThreshold {
        return WarmTier
    }
    return ColdTier
}
```

### 5.3 分层成本估算

假设总容量需求100TB：

| 层级 | 配比 | 容量 | 介质 | 单价 | 总成本 |
|------|------|------|------|------|--------|

| 冷 | 70% | 70TB | HDD | ¥45/TB | ¥3,150 |
| **合计** | 100% | 100TB | - | - | **¥9,670** |

对比纯NVMe方案: 100TB × ¥262 = ¥26,200，分层存储节省 **63%**
