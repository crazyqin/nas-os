## 品牌故事

NAS-OS 诞生于对现有 NAS 系统的不满：
- 群晖太贵，闭源锁定
- TrueNAS 太复杂，家用门槛高
- 飞牛功能少，安全弱

我们用 Go 从零构建，坚持：
1. **开源优先** - MIT 协议，代码完全开放
2. **安全第一** - WriteOnce 防勒索，AI 威胁检测
3. **AI 原生** - 本地 LLM，不依赖云端
4. **家用友好** - Web 界面，5 分钟上手
