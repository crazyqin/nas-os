# PRIVACY_POLICY.md - NAS-OS 人脸识别隐私政策

**版本**: v1.1.0  
**更新日期**: 2026-04-01  
**生效日期**: 2026-04-01  

---

## 1. 概述

NAS-OS 人脸识别功能致力于保护用户隐私，严格遵守《个人信息保护法》、《网络安全法》及相关法规。本政策说明人脸数据的收集、存储、使用和删除方式。

---

## 2. 数据收集原则

### 2.1 知情同意原则
- 启用人脸识别功能前，必须获得用户明确知情同意
- 用户有权拒绝启用人脸识别功能
- 同意记录包含：用户ID、同意时间、用途说明、政策版本

### 2.2 最小必要原则
- 仅收集必要的人脸特征向量（不存储原始人脸图像）
- 仅用于照片人物自动识别和分类
- 不收集年龄、性别、情绪等衍生信息

### 2.3 本地存储原则
- **所有人脸数据仅存储在用户的本地NAS设备上**
- 不上传至任何云端服务器
- 不与任何第三方服务共享

---

## 3. 数据存储与安全

### 3.1 存储位置
人脸数据存储于本地目录：
```
/var/lib/nas-os/face-data/
├── consents.json          # 用户同意记录
├── users/
│   ├── {userID}/
│   │   ├── faces/         # 人脸特征向量（加密存储）
│   │   ├── thumbnails/    # 人脸缩略图（可选）
│   │   ├── clusters.json  # 人物聚类分组
│   │   └── face_index.json # 人脸索引
```

### 3.2 加密存储
- 人脸特征向量采用AES-256加密存储
- 加密密钥存储于本地安全模块
- 不支持远程密钥托管

### 3.3 访问控制
- 目录权限设置为 `0700`（仅所有者可访问）
- 文件权限设置为 `0600`（仅所有者可读写）
- 禁止网络服务直接访问原始人脸数据

---

## 4. 数据保留策略

### 4.1 默认保留期限
- **默认保留365天（1年）**
- 超期数据自动清理
- 用户可自定义保留期限（0表示永久保留）

### 4.2 自动清理机制
- 每24小时检查一次过期数据
- 基于文件创建时间判断是否过期
- 清理范围：
  - 人脸特征向量文件
  - 人脸缩略图
  - 人脸索引记录

### 4.3 手动删除
用户可随时主动删除：
- 单个人脸数据
- 单个人物聚类（含所有人脸）
- 全部人脸数据（一键清除）

---

## 5. 数据导出

### 5.1 导出功能
- 用户有权导出所有人脸数据用于备份
- 导出格式：JSON结构化数据
- 导出文件需妥善保管，包含敏感人脸特征

### 5.2 导出内容
```json
{
  "userId": "user123",
  "exportTime": "2026-04-01T12:00:00Z",
  "faces": [
    {
      "id": "face_001",
      "imagePath": "/photos/2026/01/photo.jpg",
      "createdAt": "2026-01-15T08:30:00Z"
    }
  ],
  "clusters": [
    {
      "id": "cluster_001",
      "label": "家人",
      "faceIds": ["face_001", "face_002"]
    }
  ]
}
```

## 6. 数据用途限制

### 6.1 合规用途
- 照片人物自动识别
- 照片人物聚类分组
- 人物标签标注

### 6.2 禁止用途
- 不用于身份认证或访问控制
- 不用于金融交易验证
- 不用于执法或公共安全监控
- 不用于商业营销或用户画像

---

## 7. 用户权利

### 7.1 查阅权
- 查看所有人脸数据列表
- 查看人脸识别结果
- 查看数据保留策略配置

### 7.2 更正权
- 更正人物标签标注
- 合并或拆分人物聚类

### 7.3 删除权
- 删除单个人脸数据
- 删除整个人物聚类
- 删除全部人脸数据（一键清除）

### 7.4 导出权
- 导出所有人脸数据用于备份

### 7.5 撤回同意权
- 随时撤回人脸识别功能使用同意
- 撤回后系统停止人脸识别并清理数据

---

## 8. 儿童保护

### 8.1 年龄限制
- 不主动识别14岁以下儿童
- 用户标注"儿童"标签后自动限制识别范围

### 8.2 特殊保护
- 儿童人脸数据优先清理（保留期限减半）
- 不支持儿童人脸数据导出

---

## 9. 合规审计

### 9.1 日志记录

### 9.2 审计日志存储
