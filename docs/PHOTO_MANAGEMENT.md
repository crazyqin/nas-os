## 功能概述

### 什么是照片管理？

nas-os照片管理模块提供完整的照片管理解决方案，包括：
- 📸 照片上传与备份
- 🖼️ 自动缩略图生成
- 📁 相册管理
- 🗺️ 地图视图（GPS定位）
- ⏰ 时间轴浏览
- 🤖 AI智能分类与分析
- 👤 人脸识别与人物相册
- 🔍 以文搜图（自然语言搜索）

### 核心价值

| 功能 | 价值 |
|------|------|
| **本地存储** | 照片完全私有，无云端泄露风险 |
| **AI本地推理** | CLIP模型本地运行，隐私保护 |
| **以文搜图** | 自然语言搜索，无需记忆文件名 |
| **自动整理** | 智能相册、人物识别、场景分类 |

## 地图视图使用

### 功能介绍

地图视图根据照片GPS信息，在世界地图上可视化展示拍摄位置：

```
┌────────────────────────────────────────────────────────────┐
│                      🗺️ 地图视图                            │
├────────────────────────────────────────────────────────────┤
│                                                            │
│    [亚洲] [欧洲] [北美] [南美] [非洲] [大洋洲]  ← 区域筛选  │
│                                                            │
│    ┌──────────────────────────────────────────────────┐   │
│    │                                                    │   │
│    │         📍三亚 (156张)                              │   │
│    │              └─ 点击展开照片                        │   │
│    │                                                    │   │
│    │         📍北京 (89张)                               │   │
│    │                                                    │   │
│    │         📍上海 (245张)                              │   │
│    │                                                    │   │
│    └──────────────────────────────────────────────────┘   │
│                                                            │
│    [聚合显示] [列表模式] [时间筛选]                        │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 使用方法

#### WebUI操作

```bash
# 访问照片模块
http://localhost:8080/photos/

# 切换到地图视图
点击顶部导航 → "地图" 标签
```

#### 功能说明

| 功能 | 操作 |
|------|------|
| **区域筛选** | 点击地图上的区域标签 |
| **照片聚合** | 同一地点照片聚合显示 |
| **点击展开** | 点击地点查看该位置所有照片 |
| **时间筛选** | 选择时间范围过滤 |
| **缩放控制** | 滚轮或按钮缩放地图 |

#### API调用

```bash
# 获取地图数据
curl "http://localhost:8080/api/v1/photos/map" \
  -H "Authorization: Bearer TOKEN"

# 响应示例
{
  "locations": [
    {
      "city": "三亚",
      "country": "中国",
      "lat": 18.25,
      "lng": 109.51,
      "photoCount": 156,
      "coverPhotoId": "photo-001",
      "photos": ["photo-001", "photo-002", ...]
    },
    {
      "city": "北京",
      "country": "中国",
      "lat": 39.90,
      "lng": 116.40,
      "photoCount": 89,
      ...
    }
  ]
}

# 按区域获取照片
curl "http://localhost:8080/api/v1/photos/map/cluster?lat=18.25&lng=109.51&radius=50" \
  -H "Authorization: Bearer TOKEN"
```

### GPS信息要求

照片需包含GPS EXIF信息才能显示在地图上：

| 条件 | 说明 |
|------|------|
| **GPSLatitude** | 纬度坐标 |
| **GPSLongitude** | 经度坐标 |
| **GPSLatitudeRef** | 纬度参考（N/S） |
| **GPSLongitudeRef** | 经度参考（E/W） |

**无GPS照片处理**：
- 显示在"未定位"列表
- 可手动添加位置标签
- AI场景识别推断位置（规划中）

```

│                                                            │

│  └──────┘ └──────┘ └──────┘ └──────┘  → 更多              │

│  ...                                                       │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 使用方法

#### WebUI操作

```bash
# 切换到时间轴视图
点击顶部导航 → "时间轴" 标签

# 年份筛选
选择年份下拉框 → 2026

# 月份筛选
选择月份下拉框 → 3月
```

#### API调用

```bash
# 获取时间轴数据
curl "http://localhost:8080/api/v1/photos/timeline?year=2026&month=3" \
  -H "Authorization: Bearer TOKEN"

# 响应示例
{
  "timeline": {
    "2026-03-14": [
      {
        "id": "photo-001",
        "filename": "IMG_001.jpg",
        "takenAt": "2026-03-14T10:30:00Z",
        "thumbnailUrl": "/api/v1/photos/photo-001/thumbnail"
      },
      ...
    ],
    "2026-03-13": [...],
    "2026-03-10": [...]
  },
  "total": 1250
}
```

### 时间分组规则

照片按`takenAt`（拍摄时间）分组：

| 分组级别 | 说明 |
|----------|------|
| **年份** | 按年份大分组 |
| **月份** | 按月份子分组 |
| **日期** | 同一天照片聚合 |

**无拍摄时间照片**：
- 使用`createdAt`（上传时间）
- 显示在"时间未知"区域

## 智能相册配置

### 功能介绍

智能相册根据规则自动组织照片，无需手动分类：

```
┌────────────────────────────────────────────────────────────┐
│                      🤖 智能相册                            │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  系统自动创建：                                            │
│  ┌────────────────────────────────────────────────────┐   │
│  │ 🐱 宠物相册 (125张)                                 │   │
│  │    规则: object = "猫" 或 "狗"                      │   │
│  │    封面: [照片]                                      │   │
│  ├────────────────────────────────────────────────────┤   │
│  │ 🏖️ 海边相册 (89张)                                  │   │
│  │    规则: scene = "海滩"                              │   │
│  ├────────────────────────────────────────────────────┤   │
│  │ 🌅 日落相册 (45张)                                  │   │
│  │    规则: tags contains "日落"                       │   │
│  ├────────────────────────────────────────────────────┤   │
│  │ 👨‍👩‍👧‍👦 全家福相册 (156张)                              │   │
│  │    规则: person_count >= 3                          │   │
│  └────────────────────────────────────────────────────┘   │
│                                                            │
│  [+ 创建智能相册]                                          │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 创建智能相册

#### WebUI操作

1. 进入照片管理 → 智能相册
2. 点击"创建智能相册"
3. 配置规则：
   - 相册名称
   - 规则类型（标签/场景/人物/时间）
   - 规则条件
4. 保存后自动更新

#### API调用

```bash
# 创建智能相册
curl -X POST "http://localhost:8080/api/v1/photos/ai/smart-albums" \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "海边度假",
    "rule": {
      "tags": ["海边", "沙滩"],
      "scene": "海滩",
      "dateRange": {
        "start": "2026-03-01",
        "end": "2026-03-31"
      }
    }
  }'

# 响应
{
  "id": "smart-album-001",
  "name": "海边度假",
  "rule": {...},
  "photoCount": 89,
  "status": "active"
}
```

### 规则类型

| 规则类型 | 字段 | 示例 |
|----------|------|------|
| **标签匹配** | tags | `["海边", "日落"]` |
| **场景分类** | scene | `"海滩"` |
| **人物匹配** | person_ids | `["person-001"]` |
| **时间范围** | date_range | `{"start": "...", "end": "..."}` |
| **地点匹配** | location | `{"city": "三亚"}` |
| **对象检测** | objects | `["猫", "狗"]` |
| **人物数量** | person_count | `>= 3` |

### 组合规则

```json
{
  "name": "春节全家海边游",
  "rule": {
    "tags": ["春节"],
    "location": {"city": "三亚"},
    "person_count": {"min": 3},
    "date_range": {
      "start": "2026-01-20",
      "end": "2026-02-10"
    }
  }
}
```

## AI智能功能

### 人脸识别

#### 功能说明

本地AI自动检测照片中的人脸并聚类：

```bash
# 获取人物列表
curl "http://localhost:8080/api/v1/photos/persons" \
  -H "Authorization: Bearer TOKEN"

# 响应
{
  "persons": [
    {
      "id": "person-001",
      "name": "张三",
      "faceCount": 125,
      "coverFaceId": "face-001",
      "createdAt": "2026-03-01T00:00:00Z"
    },
    {
      "id": "person-002",
      "name": "李四",
      "faceCount": 89,
      ...
    }
  ]
}
```

#### 操作步骤

1. 系统自动检测人脸
2. 自动聚类相似人脸
3. 创建人物档案
4. 用户可命名人物
5. 人物相册自动生成

### 以文搜图

#### 功能说明

使用自然语言搜索照片（CLIP模型）：

```bash
# 搜索示例
curl "http://localhost:8080/api/v1/photos/search" \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "海边日落的照片",
    "limit": 20
  }'

# 响应
{
  "photos": [
    {
      "id": "photo-001",
      "score": 0.92,
      "matchReason": {
        "type": "semantic",
        "matchedOn": ["海边", "日落", "beach", "sunset"]
      }
    }
  ],
  "expandedTerms": ["海边", "日落", "beach", "sunset", "黄昏"]
}
```

#### 搜索示例

| 搜索词 | 匹配照片 |
|--------|----------|
| "海边日落" | 海滩黄昏照片 |
| "穿红衣服的人" | 红色服装人物照 |
| "去年春节" | 2025年春节照片 |
| "宠物猫" | 猫咪照片 |
| "全家福" | 多人合影 |

## 移动端备份

### iOS快捷指令

创建自动照片备份：

```
1. 打开「快捷指令」App
2. 创建新快捷指令
3. 添加操作：「获取最近的相片」
4. 添加操作：「URL」
   → http://nas-ip:8080/api/v1/photos/upload/batch
5. 添加操作：「上传文件到 URL」
6. 设置自动化：每天运行
```

### Android (Tasker)

```yaml
触发器：
  - 充电时
  - 连接到指定WiFi

动作：
  - HTTP POST
  - URL: http://nas-ip:8080/api/v1/photos/upload/batch
  - 文件: /sdcard/DCIM/Camera/
```

## 最佳实践

### 存储配置

```json
// photos-config.json
{
  "maxUploadSize": 524288000,  // 500MB
  "supportedFormats": ["jpg", "jpeg", "png", "heic", "webp"],
  "thumbnailConfig": {
    "smallSize": 128,   // 小缩略图
    "mediumSize": 512,  // 中缩略图
    "largeSize": 1024,  // 大缩略图
    "quality": 85
  },
  "aiConfig": {
    "enabled": true,
    "faceDetection": true,
    "sceneClassification": true,
    "textToImage": true
  }
}
```

### 性能优化

| 场景 | 建议 |
|------|------|
| **大量照片** | 批量索引，后台处理 |
| **大文件** | 分片上传，断点续传 |
| **AI分析** | GPU加速，批处理 |
| **缩略图** | 预生成，缓存优化 |

### 安全建议

- ✅ 启用HTTPS传输
- ✅ 设置访问权限控制
- ✅ 定期备份照片数据
- ✅ 限制外网访问
- ✅ 使用强密码认证
