## 一、功能概述

### 1.1 什么是勒索软件防护

勒索软件防护是NAS-OS的企业级安全功能，实时监控文件系统活动，检测并阻止勒索软件攻击，保护您的数据安全。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| **实时检测** | 毫秒级响应，在文件被加密前拦截攻击 |
| **行为分析** | 多规则检测引擎，识别勒索软件特征行为 |
| **熵值分析** | 检测文件内容熵值变化，识别加密行为 |
| **自动隔离** | 终止恶意进程、锁定文件、阻断网络 |
| **实时备份** | 修改前自动备份原文件，支持一键恢复 |
| **快照保护** | 防止勒索软件删除快照备份数据 |
| **多渠道告警** | 邮件/Webhook/推送通知，及时预警 |

### 1.3 竞品对标

对标TrueNAS 26勒索软件防护功能：

| 特性 | TrueNAS | NAS-OS |
|------|---------|--------|
| 快照异常检测 | ✅ | ✅ |
| 文件扩展名监控 | ✅ | ✅ |
| 熵值分析 | - | ✅ |
| 实时备份恢复 | - | ✅ |
| 快照保护机制 | ✅ | ✅ |
| 自动进程隔离 | - | ✅ |

## 二、配置说明

### 2.1 基础配置

通过WebUI「安全中心」→「勒索软件防护」进入配置页面。

#### 监控范围配置

```yaml
# 监控路径
监控目录:
  - /data          # 用户数据目录（推荐）
  - /home          # 用户主目录
  - /shares        # 共享目录

# 排除路径（不监控）
排除目录:
  - /data/cache    # 缓存目录
  - /data/tmp      # 临时文件
  - /data/backup   # 备份目录（避免误报）
```

#### 检测灵敏度配置

| 级别 | 触发阈值 | 适用场景 |
|------|----------|----------|
| **严格** | 低阈值，高敏感 | 存放重要文档的用户 |
| **标准** | 平衡阈值 | 默认推荐 |
| **宽松** | 高阈值，低敏感 | 频繁文件操作的用户 |

#### 白名单配置

白名单进程不会被检测拦截，避免误报：

```yaml
# 进程白名单
白名单进程:
  - /usr/bin/rsync      # 同步工具
  - /usr/bin/tar        # 打包工具
  - /usr/bin/zip        # 压缩工具
  - /usr/bin/rclone     # 云同步
  - /usr/bin/borg       # 备份工具

# 路径白名单
白名单路径:
  - /data/backup        # 备份目录
  - /data/archives      # 归档目录
```

### 2.2 告警配置

#### 告警渠道

| 渠道 | 配置说明 |
|------|----------|
| **邮件** | 配置SMTP服务器和收件人地址 |
| **Webhook** | 配置URL接收JSON格式告警 |
| **系统推送** | NAS WebUI实时推送通知 |
| **短信** | 需配置短信网关（可选） |

#### 告警级别设置

| 级别 | 说明 | 建议告警渠道 |
|------|------|--------------|
| **可疑** | 持续监控，记录日志 | 系统推送 |
| **高风险** | 准备隔离，加强监控 | 邮件+推送 |
| **确认攻击** | 立即隔离，触发恢复 | 邮件+Webhook+推送 |
| **紧急** | 已造成损害，全渠道告警 | 所有渠道 |

### 2.3 恢复配置

```yaml
# 实时备份配置
实时备份:
  启用: true
  备份路径: /var/lib/nas-os/ransomware-backup
  最大空间: 10GB              # 备份空间上限
  保留天数: 30                # 备份保留时间
  
# 快照保护配置  
快照保护:
  启用: true
  保护策略: auto             # 自动保护关键快照
```

### 2.4 防护响应配置

```yaml
# 防护动作配置
防护响应:
  自动隔离: true             # 检测到攻击后自动隔离
  终止进程: true             # 终止恶意进程
  锁定文件: true             # 锁定受影响目录
  阻断网络: false            # 阻断网络访问（谨慎启用）
  创建快照: true             # 防护前创建应急快照
```

## 三、使用流程

### 3.1 开启防护

1. 登录NAS-OS WebUI
2. 进入「安全中心」→「勒索软件防护」
3. 点击「开启防护」按钮
4. 配置监控目录和白名单
5. 保存配置，防护立即生效

### 3.2 查看威胁面板

威胁面板显示实时检测结果：

| 信息 | 说明 |
|------|------|
| **防护状态** | 开启/关闭，运行状态 |
| **检测事件** | 最近检测到的威胁事件 |
| **威胁等级** | 当前威胁级别评估 |
| **隔离进程** | 已隔离的恶意进程列表 |
| **恢复记录** | 可恢复的文件备份记录 |

### 3.3 响应威胁事件

#### 发现威胁时

当检测到可疑活动时：

1. **可疑级别**：系统记录日志，持续监控
2. **高风险级别**：系统准备隔离，发送告警通知
3. **确认攻击**：系统自动执行防护响应

#### 手动操作

管理员可手动执行：

- **查看详情**：点击事件查看完整分析报告
- **确认威胁**：确认后立即执行隔离
- **解除误报**：标记为误报，加入白名单
- **忽略事件**：忽略此事件，不做处理

### 3.4 数据恢复流程

#### 单文件恢复

1. 进入「安全中心」→「勒索软件防护」→「恢复」
2. 选择需要恢复的文件
3. 点击「恢复原文件」
4. 等待恢复完成

#### 批量恢复

1. 选择时间范围（攻击发生时段）
2. 点击「批量恢复」
3. 系统恢复该时段所有被修改的文件
4. 查看恢复报告，确认恢复结果

#### 从快照恢复

如果实时备份不足，可从快照恢复：

1. 进入「存储管理」→「快照」
2. 选择攻击前的快照
3. 点击「回滚」或「克隆」
4. 验证数据完整性

## 四、检测原理

### 4.1 行为分析检测

系统监控以下勒索软件特征行为：

| 行为特征 | 检测条件 | 权重 |
|----------|----------|------|
| **快速批量修改** | 10秒内修改50+文件 | 高 |
| **可疑扩展名** | 文件扩展名变为 `.encrypted` `.locked` 等 | 高 |
| **批量删除** | 30秒内删除100+文件 | 高 |
| **删除卷影副本** | 尝试删除系统快照（VSS等） | 最高 |
| **深度目录遍历** | 短时间访问20+不同目录 | 中 |

### 4.2 熵值分析检测

勒索软件加密文件后，文件熵值显著升高：

| 文件类型 | 正常熵值 | 加密后熵值 |
|----------|----------|------------|
| 文本文件 | 4.0-5.5 | 接近8.0 |
| 图片文件 | 5.5-7.0 | 接近8.0 |
| 压缩文件 | 7.0-7.8 | 接近8.0 |

当检测到文件熵值突然升高，系统判定为加密行为。

### 4.3 快照异常检测

系统监控快照空间变化：

| 异常类型 | 检测条件 |
|----------|----------|
| **空间突增** | 快照空间突然增长500%+ |
| **快照删除** | 关键快照被删除 |
| **频繁快照操作** | 短时间内大量快照创建/删除 |

## 五、常见问题

### Q1: 防护会影响NAS性能吗？

**A**: 系统开销控制在5%以内。通过智能事件过滤、异步处理、缓存优化等技术，对日常使用影响极小。

### Q2: 备份操作被误判为勒索软件怎么办？

**A**: 将备份工具加入白名单进程：
- rsync
- tar
- zip
- rclone
- borg

这些常见备份工具已在默认白名单中。

### Q3: 加密软件（如7-Zip）会被误判吗？

**A**: 正常压缩软件不会触发检测。系统区分：
- **正常压缩**：单个文件或少量文件压缩，目的文件扩展名正常
- **勒索软件**：批量修改大量文件，扩展名变为可疑类型

如遇误报，可加入白名单。

### Q4: 防护功能需要额外硬件吗？

**A**: 不需要。勒索软件防护是纯软件功能，无需额外硬件投入。备份存储使用现有存储空间。

### Q5: 备份空间不够怎么办？

**A**: 系统提供以下策略：
- 设置备份空间上限（默认10GB）
- 超出上限时删除最早备份
- 可手动清理不需要的备份
- 重要数据建议依赖快照备份

### Q6: 防护失败数据被加密怎么办？

**A**: 多层恢复机制：
1. **实时备份恢复**：被加密文件的原始备份
2. **快照回滚**：回滚到攻击前的快照
3. **离线备份恢复**：从外部备份恢复数据

建议定期创建并验证快照。

### Q7: 如何验证防护功能有效？

**A**: 建议在测试环境验证：
1. 创建测试目录和测试文件
2. 模拟勒索软件行为（批量修改文件扩展名）
3. 观察是否触发检测和告警
4. 验证恢复功能

**切勿在生产环境测试！**

### Q8: 多用户环境下如何配置？

**A**: 针对不同用户需求：
- **普通用户**：启用标准防护，监控共享目录
- **重要数据用户**：启用严格防护，加强告警
- **技术用户**：配置宽松防护，减少干扰

可为不同目录设置不同灵敏度。

## 六、最佳实践

### 6.1 推荐配置

1. **监控范围**：监控所有用户数据目录，排除系统目录和缓存目录
2. **灵敏度**：默认标准，重要数据使用严格模式
3. **白名单**：添加所有备份和同步工具
4. **告警**：配置邮件+Webhook双重告警
5. **快照**：定期创建快照，保留至少7天

### 6.2 定期检查

- 每周查看威胁面板，了解检测事件
- 每月验证恢复功能有效性
- 每季度更新白名单和检测规则

### 6.3 安全建议

- 保持NAS系统更新
- 使用强密码保护管理员账户
- 限制外部访问，使用VPN或Tunnel
- 定期备份关键数据到外部存储
- 不运行未知来源的应用程序
