## 5. 设计原则

### 5.1 UX原则
1. **一目了然**: 关键信息可见
2. **操作便捷**: 快速操作入口
3. **响应迅速**: 界面加载优化
4. **移动友好**: 响应式设计

### 5.2 视觉设计
- 保持现有深色/浅色主题
- 信息层级清晰
- 操作按钮醒目
- 状态标识明确
