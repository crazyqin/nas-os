## 1. 功能概述

### 1.1 支持的存储平台

| 类别 | 提供商 |
|------|--------|
| **国际云存储** | AWS S3、阿里云 OSS、腾讯云 COS、Backblaze B2、WebDAV |
| **常用网盘** | Google Drive、OneDrive、Dropbox |
| **中国网盘** | 115网盘、夸克网盘、阿里云盘、百度网盘 |

### 1.2 同步模式

| 模式 | 说明 |
|------|------|
| **双向同步（Sync）** | 本地 ↔ 云端实时保持一致 |
| **上传（Upload）** | 仅将本地变更同步至云端 |
| **下载（Download）** | 仅将云端变更同步至本地 |

### 1.3 核心特性

- 🚀 **增量同步** — 仅传输变更部分，节省带宽
- 🔄 **实时同步** — 文件变更即时检测，自动触发同步
- 🛡️ **冲突处理** — 三种策略处理文件同时修改
- ⚡ **带宽控制** — 限制上传/下载速度，不影响正常上网
- 📜 **版本历史** — 保留30天同步记录，可回溯

## 2. 快速入门

### 2.1 通过 Web UI

1. 登录 nas-os Web 管理界面
2. 进入 **应用中心** → **Drive Sync**
3. 点击 **添加任务** 创建第一个同步任务

### 2.2 通过 CLI

```bash
# 列出所有同步任务
nasctl sync list

# 创建同步任务
nasctl sync create \
  --name "我的文档备份" \
  --source "/mnt/pool/Documents" \
  --target "s3://my-bucket/docs" \
  --direction "bidirectional" \
  --conflict "newer_wins"

# 启动同步
nasctl sync start <task-id>

# 查看状态
nasctl sync status <task-id>
```

## 3. 创建同步任务

### 3.1 基本配置

```
任务名称: 我的文档备份
同步方向: 双向同步
冲突处理: 保留最新版本
```

### 3.2 来源与目标

- **本地路径**: `/mnt/pool/Documents/`
- **目标存储**: S3 bucket、或其他支持的云存储

### 3.3 高级选项

- **带宽限制**: 默认无限制，可设置上传/下载速度上限
- **同步过滤**: 可排除特定文件/文件夹（如 `.DS_Store`、`*.tmp`）
- **计划任务**: 手动触发 / 定时同步 / 实时监控

## 4. 管理同步任务

### 4.1 任务状态

| 状态 | 说明 |
|------|------|
| 🟢 `synced` | 同步完成，两端一致 |
| 🔄 `syncing` | 同步进行中 |
| 🟡 `pending` | 等待中 |
| 🔴 `error` | 同步出错 |
| 🟠 `conflict` | 存在冲突文件，需手动处理 |

### 4.2 操作

- **启动/暂停** — 随时控制同步任务
- **删除** — 移除同步任务（不影响原始文件）
- **查看详情** — 查看同步统计、错误日志

## 5. 冲突处理

当同一文件在本地和云端同时被修改时，系统按以下策略处理：

| 策略 | 行为 |
|------|------|
| **保留最新（newer_wins）** | 比较修改时间，保留最新版本 |
| **保留双方（keep_both）** | 旧文件保留，新文件加时间戳后缀 |
| **询问（ask）** | 暂停同步，等待用户选择 |

> 💡 **建议**: 大多数用户推荐使用 `newer_wins`，自动处理无需干预。

## 6. 带宽控制

在高级设置中可配置带宽限制：

| 设置项 | 说明 |
|--------|------|
| 上传限速 | 0 = 无限制，单位：KB/s 或 MB/s |
| 下载限速 | 0 = 无限制 |

**示例**：
```
上传限速: 2 MB/s  （适合家庭宽带上行较小的场景）
下载限速: 5 MB/s
```

## 7. 同步历史

- 保留最近 **30天** 的同步记录
- 记录包含：文件名、操作类型（上传/下载/跳过）、时间戳
- 支持按任务筛选、按时间范围搜索

## 8. FAQ

**Q: 同步中断后会自动续传吗？**  
A: 是的，Drive Sync 支持断点续传，中断后可继续同步。

**Q: 可以同步 symbolic link 吗？**  
A: 当前版本仅同步实际文件，符号链接将被跳过。

**Q: 如何排除特定文件？**  
A: 在任务设置 → 过滤规则中添加排除模式，如 `*.tmp`、`node_modules/`。

**Q: 与 Synology Drive 有什么区别？**  
A: nas-os Drive Sync 对接更多中国本地云存储（阿里云盘、百度网盘、115等），且完全免费、无厂商绑定。
