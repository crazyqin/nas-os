# 人脸识别与人物相册 (Face Recognition)

> **适用版本**: v2.482.0+ | **模块**: `internal/photos/face`

本地 AI 人脸识别功能，自动检测照片中的人脸、提取特征、智能聚类并生成人物相册，全部在本地完成，零数据外泄。

## 核心特性

| 特性 | 说明 |
|------|------|
| 🔍 人脸检测 | 自动识别照片中的所有人脸，支持单张照片最多 50 张人脸 |
| 🧬 特征提取 | 512 维嵌入向量（ArcFace 模型），精度高、误识率低 |
| 🧠 智能聚类 | DBSCAN 算法自动将同一人的照片归为一组 |
| 🏷️ 人物标签 | 为聚类命名（如"爸爸"、"妈妈"），快速生成人物相册 |
| ⚡ Intel QSV 加速 | 支持 Intel 核显硬件加速，推理速度提升 3-5 倍 |
| 🔗 外部服务 | 可接入外部人脸识别 API（如 DeepFace、InsightFace 服务） |
| 🖥️ GPU 加速 | 支持 NVIDIA GPU 加速推理 |

## 识别流程

```
照片上传/扫描 → 人脸检测 → 特征提取(512维向量) → 聚类分组 → 人工/自动标记 → 人物相册
```

1. **检测**：从照片中定位所有人脸，输出边界框、置信度、质量评分
2. **提取**：为每张人脸生成 512 维嵌入向量
3. **聚类**：DBSCAN 算法将相似向量归为同一人物
4. **标记**：用户为聚类命名，或系统自动根据已有标记推断

## 配置参数

### 检测参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `minFaceSize` | 30 | 最小人脸尺寸（像素），低于此值忽略 |
| `maxFacesPerPhoto` | 50 | 单张照片最大检测人脸数 |
| `detectionModel` | `hog` | 检测模型：`hog`（轻量）/ `retinaface`（精确）/ `mtcnn`（平衡） |
| `confidenceThresh` | 0.8 | 检测置信度阈值，低于此值丢弃 |

### 识别参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `recognitionModel` | `arcface` | 识别模型：`arcface` / `facenet` / `insightface` |
| `embeddingSize` | 512 | 嵌入向量维度 |
| `clusterThresh` | 0.6 | 聚类相似度阈值（0-1），越低越宽松 |
| `minClusterSize` | 2 | 最小聚类大小，少于此数的不生成人物 |

### 性能参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `useGPU` | false | 启用 GPU 加速 |
| `batchSize` | 32 | 批处理大小 |
| `numWorkers` | 4 | 并行工作线程数 |
| `useExternalService` | false | 使用外部人脸识别服务 |
| `externalServiceUrl` | — | 外部服务地址 |

## Intel QSV 硬件加速

NAS-OS 支持 Intel Quick Sync Video 核显加速人脸检测推理：

- **设备检测**：自动识别 Intel GPU 设备
- **模型加速**：检测模型运行在 Intel 核显上，CPU 释放给其他任务
- **适用场景**：Intel 11 代以上处理器（Rocket Lake+）

启用方式：将配置中 `detectionModel` 设为支持 QSV 的模型，系统自动使用核显加速。

## 使用场景

- **家庭相册**：自动按人物整理照片，快速找到"宝宝"的所有照片
- **旅行合照**：自动识别合影中的每个人，生成各自的旅行记忆
- **事件回顾**：按人物聚合照片，回忆特定人的故事

## 最佳实践

1. **首次扫描**：建议先对已有照片库执行批量扫描
2. **阈值调整**：如果误识别多，提高 `clusterThresh`；如果漏识别多，降低它
3. **逐步标记**：先标记确定的人物，聚类会越来越准
4. **定期重聚类**：照片增多后重新聚类，分类更精确
