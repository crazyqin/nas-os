# Scrub 智能调度使用指南

> **版本**: v2.481.0  
> **更新日期**: 2026-05-02

---

## 概述

Scrub（数据校验）是 ZFS 存储池的定期一致性检查机制。NAS-OS 的 Scrub 智能调度系统会自动避开业务高峰时段执行，减少对正常业务的影响。

### 为什么需要 Scrub

- 检测并修复静默数据损坏（bit rot）
- 验证存储池数据完整性
- 提前发现磁盘潜在问题
- 确保冗余数据一致性

### 智能调度特性

- **避峰执行** - 自动避开业务高峰时段
- **负载感知** - 系统高负载时自动降速或暂停
- **优先级管理** - 关键业务优先，Scrub 让路
- **进度记忆** - 中断后自动续扫，不重复扫描

## 配置 Scrub 调度

### 基本设置

1. 进入「存储」→「维护」→「Scrub 调度」
2. 选择存储池
3. 配置调度参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 执行周期 | Scrub 执行间隔 | 14 天 |
| 避峰时段 | 不执行 Scrub 的时间段 | 09:00-18:00 |
| 最大持续时间 | 单次 Scrub 最长时间 | 12 小时 |
| I/O 限制 | Scrub 读取速度上限 | 200MB/s |

### 避峰策略

```yaml
# 避峰配置示例
scrub_schedule:
  pool: tank
  interval_days: 14
  avoidance:
    peak_hours:
      - start: "09:00"
        end: "18:00"
        days: [mon, tue, wed, thu, fri]
    special_dates:
      - type: holiday
        action: skip      # 节假日跳过
      - type: backup
        action: defer      # 备份期间推迟
  throttle:
    max_read_mbps: 200
    pause_on_cpu_above: 80    # CPU > 80% 时暂停
    pause_on_iops_above: 1000 # IOPS > 1000 时降速
```

### 高级选项

- **优先级模式** - 低/中/高（影响 CPU 和 I/O 资源分配）
- **并发控制** - 是否同时对多个池执行 Scrub
- **错误阈值** - 达到多少错误后自动停止并告警
- **完成通知** - Scrub 完成后发送通知

## 监控 Scrub 状态

### 实时查看

进入「存储」→「维护」→「Scrub 状态」：

| 指标 | 说明 |
|------|------|
| 进度百分比 | 当前扫描进度 |
| 已扫描数据 | 已校验的数据量 |
| 扫描速度 | 当前 I/O 读取速度 |
| 预计剩余时间 | 根据当前速度估算 |
| 发现错误 | 检测到的数据错误数 |
| 修复状态 | 已自动修复的错误数 |

### 历史记录

查看历史 Scrub 执行记录：
- 执行时间、持续时长
- 扫描的数据量
- 发现和修复的错误
- 是否被中断及原因

## 常见问题

### Q: Scrub 期间系统变慢？

调整建议：
1. 降低 Scrub I/O 限制
2. 设置更宽的避峰时段
3. 使用「低优先级」模式

### Q: Scrub 频繁被中断？

检查：
1. 避峰时段是否设置过宽
2. 系统负载是否持续偏高
3. 考虑延长最大持续时间

### Q: Scrub 发现错误怎么办？

1. 查看错误详情（哪些文件受影响）
2. 如果是冗余数据可修复，系统自动修复
3. 如果无法修复，考虑从备份恢复受影响文件
4. 检查对应磁盘的 SMART 状态
