# SMART 定时任务用户指南

## 概述

SMART 定时任务功能允许您配置自动化的磁盘健康检查，定期执行 SMART 测试以确保存储设备的可靠性。通过预设的时间计划，系统会自动检测磁盘状态，并在发现问题时及时告警。

## 功能特性

- **定时检查**: 支持 Cron 表达式配置执行时间
- **多种测试**: 短测试、长测试、运输测试、离线测试
- **多设备支持**: 同时监控多个磁盘设备
- **实时告警**: 温度异常、扇区错误、健康下降等告警
- **历史记录**: 查看测试结果和告警历史
- **可视化界面**: 直观的 Web 界面管理

## 访问方式

在 NAS-OS Web 界面中，导航至 **硬件管理 > SMART 定时任务** 页面。

页面地址: `/pages/hardware/smart-cron.html`

## 界面说明

### 1. 任务配置

任务配置页面显示所有已创建的 SMART 定时任务列表。

#### 任务列表字段

| 字段 | 说明 |
|------|------|
| 任务名称 | 自定义的任务标识名称 |
| 测试类型 | SMART 测试类型（短测试/长测试等） |
| 执行时间 | Cron 表达式及人性化描述 |
| 目标设备 | 任务监控的磁盘设备列表 |
| 状态 | 已启用/已禁用 |
| 操作 | 编辑、启用/禁用、删除 |

#### 创建任务

点击页面右上角的 **"+ 新建任务"** 按钮，打开任务创建表单：

1. **任务名称**: 输入易于识别的名称，如"每周 NVMe 健康检查"
2. **测试类型**: 选择测试类型
   - **短测试** (~2分钟): 快速检查，适合频繁执行
   - **长测试** (完整扫描): 详细检查，耗时较长
   - **运输测试**: 验证运输后的设备状态
   - **离线测试**: 系统低负载时执行
3. **执行时间**: 使用 Cron 表达式或选择预设
4. **目标设备**: 选择要检查的磁盘设备
5. **启用状态**: 是否立即启用任务
6. **通知设置**: 配置告警通知选项

#### Cron 表达式说明

标准 5 字段格式: `分 时 日 月 周`

常用预设:

| 预设 | 表达式 | 含义 |
|------|--------|------|
| 每周日凌晨2点 | `0 2 * * 0` | 适合周末执行长测试 |
| 每日凌晨3点 | `0 3 * * *` | 每日快速检查 |
| 每周六凌晨4点 | `0 4 * * 6` | 周末维护检查 |
| 每月1号 | `0 0 1 * *` | 月度完整检测 |
| 每6小时 | `0 */6 * * *` | 高频监控 |

#### 编辑任务

点击任务行的 **编辑** 按钮（✎），可修改任务配置。

#### 启用/禁用任务

点击 **启用/禁用** 按钮（▶/⏸），切换任务状态。禁用的任务不会自动执行。

#### 删除任务

点击 **删除** 按钮（✕），确认后删除任务。

### 2. 执行状态

查看当前正在执行的 SMART 测试任务。

显示信息:
- 正在执行的任务名称
- 开始时间
- 测试进度百分比
- 当前测试的设备

进度条实时更新测试完成进度。

### 3. 检查结果

查看历史 SMART 测试结果记录。

#### 筛选条件

- **设备**: 筛选特定设备的测试结果
- **结果状态**: 通过/警告/失败
- **测试类型**: 短测试/长测试等

#### 结果字段

| 字段 | 说明 |
|------|------|
| 执行时间 | 测试完成时间 |
| 设备 | 测试的磁盘设备 |
| 测试类型 | 执行的测试类型 |
| 结果 | 通过/警告/失败 |
| 健康分数 | 设备健康评分 (0-100%) |
| 详情 | 查看详细信息 |

#### 结果状态说明

- **通过** ✓: 设备健康状态良好
- **警告** ⚠: 发现轻微问题，需关注
- **失败** ✗: 发现严重问题，建议更换

### 4. 告警历史

查看系统产生的磁盘健康告警记录。

#### 告警级别

| 级别 | 图标 | 说明 |
|------|------|------|
| 严重 | 🔴 | 需立即处理的问题 |
| 警告 | ⚠️ | 需关注的问题 |
| 信息 | ℹ️ | 一般性通知 |

#### 常见告警类型

- **温度异常**: 温度超过阈值（默认警告 50°C，严重 60°C）
- **重分配扇区**: 扇区被重新分配（表明磁盘老化）
- **待映射扇区**: 扇区等待重新分配
- **SMART 失败**: SMART 自检失败
- **CRC 错误**: 数据传输错误
- **寻道错误**: 磁头寻道异常

## 最佳实践

### 1. 任务配置建议

**NVMe SSD 设备**:
- 每周一次短测试即可
- 长测试不推荐频繁执行（影响 SSD 寿命）
- 关注温度和使用百分比指标

**机械硬盘 (HDD)**:
- 每日短测试适合重要数据盘
- 每月一次长测试用于深度检查
- 关注重分配扇区和待映射扇区

### 2. 执行时间选择

- **避开高峰期**: 选择系统低负载时段（凌晨 2-5 点）
- **错开设备**: 多设备任务可分批执行，避免资源竞争
- **留出间隔**: 测试之间保持足够间隔时间

### 3. 告警处理流程

1. **信息级别**: 查看详情，了解情况
2. **警告级别**: 检查设备状态，准备备份
3. **严重级别**: 
   - 立即备份重要数据
   - 规划设备更换
   - 如必要，临时禁用设备

### 4. 定期维护

- 每月查看检查结果汇总
- 关注健康分数变化趋势
- 及时处理待映射扇区
- 更换健康分数低于 70% 的设备

## API 接口

前端通过以下 API 与后端交互：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/smart-cron/tasks` | GET | 获取任务列表 |
| `/api/v1/smart-cron/tasks` | POST | 创建新任务 |
| `/api/v1/smart-cron/tasks/:id` | PUT | 更新任务 |
| `/api/v1/smart-cron/tasks/:id` | DELETE | 删除任务 |
| `/api/v1/smart-cron/tasks/:id/toggle` | POST | 启用/禁用任务 |
| `/api/v1/smart-cron/tasks/:id/run` | POST | 立即执行任务 |
| `/api/v1/smart-cron/executions` | GET | 获取执行状态 |
| `/api/v1/smart-cron/results` | GET | 获取检查结果 |
| `/api/v1/smart-cron/alerts` | GET | 获取告警历史 |
| `/api/v1/disks` | GET | 获取磁盘设备列表 |

## 常见问题

### Q: 测试执行时间过长怎么办？

A: 长测试可能需要数小时，建议：
- 使用短测试进行日常检查
- 长测试安排在夜间或维护时段
- 大容量设备测试时间更长，需耐心等待

### Q: 如何判断磁盘是否需要更换？

A: 关注以下指标：
- 健康分数持续低于 70%
- 重分配扇区持续增加
- SMART 状态显示 FAILED
- 温度异常无法改善

### Q: 测试会影响系统性能吗？

A: SMART 测试会占用磁盘 I/O：
- 短测试影响较小
- 长测试期间磁盘性能下降
- 建议低负载时段执行
- 可在任务配置中设置并发限制

### Q: 如何禁用特定设备的测试？

A: 编辑任务，从目标设备列表中移除该设备，或创建单独任务管理。
