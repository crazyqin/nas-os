# TrueSearch 使用指南

**适用版本**: nas-os v2.463.0+
**更新日期**: 2026-04-29

---

## 1. TrueSearch 简介

TrueSearch 是 nas-os 的全文内容搜索引擎，对标 TrueNAS 26 的 TrueSearch 功能。它不仅搜索文件名，还能深入文件内容进行全文检索。

### 核心能力

| 能力 | 说明 |
|------|------|
| **全文内容搜索** | 搜索 PDF、Word、Markdown、TXT 等文件的实际内容 |
| **多语言分词** | 支持中文、英文、日文智能分词 |
| **实时增量索引** | 文件变更后 5 分钟内自动更新索引 |
| **高亮显示** | 搜索结果中高亮匹配的关键词 |
| **类型过滤** | 按文件类型（文档/图片/视频/代码）过滤结果 |
| **路径限定** | 指定搜索范围，缩小结果集 |

### 与文件名搜索的区别

| 搜索方式 | 文件名搜索 | TrueSearch |
|----------|-----------|------------|
| 搜索范围 | 仅文件名 | 文件名 + 文件内容 |
| 支持格式 | 所有文件 | PDF/Word/MD/TXT/代码等 |
| 分词支持 | ❌ 精确匹配 | ✅ 中英文智能分词 |
| 搜索速度 | 极快（<10ms） | 快（<50ms） |
| 索引空间 | 无 | 约为内容的 1/5 |

## 2. 快速开始

### 2.1 确认 TrueSearch 已启用

TrueSearch 在 nas-os 安装时默认启用。检查状态：

1. 进入 **控制面板** → **搜索服务**
2. 确认 **TrueSearch** 状态为 **运行中**

或通过命令行：

```bash
# 查看索引状态
curl -s http://localhost:8080/api/v1/search/status | jq

# 返回示例
{
  "total_files": 12580,
  "indexed_files": 12576,
  "pending_files": 4,
  "last_update": "2026-04-29T20:15:00Z",
  "index_size": "2.3GB"
}
```

### 2.2 第一次搜索

1. 打开 nas-os Web 界面
2. 点击顶部 **搜索栏**（或按 `Ctrl+K` / `Cmd+K`）
3. 输入关键词，如 `项目报告`
4. 结果将在 50ms 内返回，匹配内容会高亮显示

## 3. 搜索语法

### 3.1 基本搜索

直接输入关键词即可：

```
项目报告
```

支持中英文混合搜索：

```
Q2 revenue 报告
```

### 3.2 短语搜索

用双引号精确匹配短语：

```
"年度财务报告"
```

### 3.3 文件类型过滤

使用 `type:` 限定文件类型：

```
会议记录 type:pdf
项目方案 type:docx
配置说明 type:markdown
```

支持的类型：`pdf`, `docx`, `doc`, `xlsx`, `pptx`, `md`, `txt`, `csv`, `json`, `yaml`, `py`, `go`, `js`

### 3.4 路径限定

使用 `path:` 缩小搜索范围：

```
合同 path:/documents/contracts
报告 path:/shared/reports/2026
```

### 3.5 日期过滤

使用 `after:` 和 `before:` 按修改日期过滤：

```
会议纪要 after:2026-04-01
预算 before:2026-03-31
计划 after:2026-01-01 before:2026-06-30
```

### 3.6 组合搜索

多个条件可以自由组合：

```
"季度报告" type:pdf path:/finance after:2026-01-01
```

## 4. Web 界面使用

### 4.1 搜索面板

- **搜索栏**: 顶部全局搜索，支持快捷键 `Ctrl+K` / `Cmd+K`
- **高级搜索**: 点击搜索栏右侧的筛选图标展开高级选项
- **搜索历史**: 点击搜索栏查看最近 20 条搜索记录

### 4.2 结果展示

每条搜索结果包含：

| 字段 | 说明 |
|------|------|
| **文件名** | 匹配的文件名称 |
| **路径** | 文件完整路径 |
| **匹配片段** | 包含关键词的内容摘要（高亮） |
| **相关度** | 搜索得分，越高越相关 |
| **修改时间** | 文件最后修改时间 |
| **文件大小** | 文件大小 |

### 4.3 结果操作

- **点击文件名** — 直接打开文件
- **点击路径** — 导航到文件所在目录
- **右键菜单** — 下载、分享、查看详情

## 5. API 使用

### 5.1 搜索接口

```bash
curl -X POST http://localhost:8080/api/v1/search \
  -H "Content-Type: application/json" \
  -d '{
    "query": "项目报告",
    "path": "/documents",
    "types": ["pdf", "docx"],
    "max_results": 20,
    "highlight": true
  }'
```

**返回示例**:

```json
{
  "results": [
    {
      "path": "/documents/2026/Q2-report.pdf",
      "name": "Q2-report.pdf",
      "size": 2048576,
      "mod_time": "2026-04-15T10:30:00Z",
      "score": 0.95,
      "snippet": "...本季度<em>项目报告</em>涵盖三个核心方向..."
    }
  ],
  "total": 15,
  "took_ms": 23,
  "highlights": {
    "/documents/2026/Q2-report.pdf": "...本季度<em>项目报告</em>涵盖三个核心方向..."
  }
}
```

### 5.2 查询参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | ✅ | 搜索关键词 |
| `path` | string | ❌ | 搜索路径范围 |
| `types` | string[] | ❌ | 文件类型过滤 |
| `languages` | string[] | ❌ | 语言过滤（zh/en/ja） |
| `max_results` | int | ❌ | 最大结果数（默认20，最大100） |
| `highlight` | bool | ❌ | 是否高亮匹配（默认true） |

### 5.3 索引管理接口

```bash
# 查看索引状态
curl -s http://localhost:8080/api/v1/search/status

# 触发重新索引
curl -X POST http://localhost:8080/api/v1/search/reindex \
  -H "Content-Type: application/json" \
  -d '{"path": "/documents", "force": false}'

# 强制重建全量索引
curl -X POST http://localhost:8080/api/v1/search/reindex \
  -H "Content-Type: application/json" \
  -d '{"path": "/", "force": true}'
```

## 6. 索引管理

### 6.1 索引范围

默认索引所有共享文件夹。可在 **控制面板** → **搜索服务** → **索引设置** 中调整：

- **包含路径**: 指定需要索引的目录
- **排除路径**: 排除不需要索引的目录（如临时文件、缓存）
- **排除模式**: 按文件名模式排除（如 `*.tmp`, `.git/*`）

### 6.2 支持的文件格式

| 类别 | 格式 | 提取方式 |
|------|------|----------|
| 文档 | PDF, DOCX, DOC, XLSX, PPTX | 内容全文提取 |
| 文本 | TXT, MD, CSV, JSON, YAML | 直接读取 |
| 代码 | PY, GO, JS, TS, JAVA, C, CPP | 直接读取 |
| 图片 | JPG, PNG, GIF | 仅索引文件名和EXIF |
| 视频 | MP4, MKV, AVI | 仅索引文件名和元数据 |

### 6.3 增量索引机制

- **实时监控**: 通过 fsnotify 监控文件系统变更
- **增量更新**: 仅处理变更文件，不重建全量索引
- **更新频率**: 文件变更后 5 分钟内自动索引
- **批量处理**: 大量文件变更时自动合并处理，减少IO压力

### 6.4 索引大小与性能

| 指标 | 参考值 |
|------|--------|
| 索引大小 | 约为原始内容的 1/5 |
| 索引速度 | 150 文件/分钟 |
| 搜索延迟 | <50ms |
| 内存占用 | ~300MB |

## 7. 多语言支持

### 7.1 中文分词

TrueSearch 使用 jieba 分词引擎处理中文：

- **精确模式**: 适合搜索场景，将句子精确切分
- **新词识别**: 自动识别新词和专有名词
- **用户词典**: 支持自定义词典，提升专业术语识别率

### 7.2 添加自定义词典

```bash
# 创建词典文件
cat > /etc/nas-os/truesearch/userdict.txt << EOF
项目管理 5 nz
云原生 5 nz
微服务架构 5 nz
EOF

# 重启索引服务使词典生效
systemctl restart nas-truesearch
```

### 7.3 语言自动检测

TrueSearch 自动检测文档语言并应用对应的分词策略，无需手动配置。混合语言文档也能正确处理。

## 8. 性能优化

### 8.1 搜索加速技巧

- **路径限定**: 指定 `path:` 缩小搜索范围
- **类型过滤**: 使用 `type:` 过滤不需要的文件类型
- **精确短语**: 用双引号 `""` 精确匹配，减少结果数量

### 8.2 索引优化

- **排除大型媒体文件**: 视频/音频文件只索引文件名，不提取内容
- **调整索引路径**: 只索引需要搜索的目录
- **定期清理**: 删除过期索引条目

```bash
# 清理已删除文件的索引
curl -X POST http://localhost:8080/api/v1/search/cleanup
```

### 8.3 资源限制

在 **控制面板** → **搜索服务** → **性能设置** 中可调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最大内存 | 512MB | 索引服务最大内存使用 |
| 索引线程数 | 2 | 并行索引线程 |
| IO优先级 | low | 索引IO优先级，避免影响正常文件访问 |

## 9. 故障排查

### 9.1 搜索无结果

1. 确认文件已被索引：检查 `/api/v1/search/status` 中 `pending_files`
2. 确认文件类型在支持列表中
3. 尝试重新索引该目录：

```bash
curl -X POST http://localhost:8080/api/v1/search/reindex \
  -d '{"path": "/your/path", "force": true}'
```

### 9.2 搜索结果不准确

1. 检查是否需要添加自定义词典
2. 尝试使用精确短语搜索（双引号）
3. 确认文件编码正确（UTF-8）

### 9.3 索引速度慢

1. 检查磁盘IO是否饱和
2. 减少索引线程数以降低IO压力
3. 排除大文件和不需要的目录

### 9.4 内存占用过高

1. 在性能设置中降低最大内存限制
2. 减少索引范围
3. 重启索引服务释放内存

```bash
# 重启索引服务
systemctl restart nas-truesearch
```

## 11. 常见问题

**Q: TrueSearch 会消耗很多系统资源吗？**
A: 日常运行内存占用约 300MB，CPU 占用极低。索引阶段 IO 优先级设为 low，不影响正常文件访问。

**Q: 新添加的文件多久能被搜索到？**
A: 通常 5 分钟内自动索引。也可通过 API 手动触发即时索引。

**Q: 支持搜索压缩包内的文件吗？**
A: 当前版本不支持。文件需要解压后才能被索引。

**Q: 索引数据存储在哪里？**
A: 存储在 `/var/lib/nas-os/truesearch/` 目录，建议放在 SSD 上以获得最佳性能。

**Q: 如何备份索引数据？**
A: 索引可随时从原始文件重建，无需单独备份。如需备份，复制 `/var/lib/nas-os/truesearch/` 目录即可。

**Q: TrueSearch 和 macOS Spotlight 冲突吗？**
A: 不冲突。TrueSearch 是独立的搜索引擎，SMB Spotlight 功能通过 mdfind 协议与 macOS 集成，两者可同时使用。
