# Audio Station 音乐中心使用指南

> **版本**: v2.482.0  
> **更新日期**: 2026-05-02

---

## 概述

Audio Station 是 NAS-OS 内置的音乐管理与播放中心，提供音乐库管理、在线播放、播放列表、多设备投送等功能。

### 主要功能

- **音乐库管理** - 自动扫描并分类您的音乐文件
- **多格式支持** - MP3、FLAC、AAC、OGG、WAV、APE、DSD 等
- **在线播放** - 浏览器端 Web 播放器，无需安装客户端
- **播放列表** - 创建、编辑、导入/导出播放列表
- **专辑封面** - 自动抓取元数据和封面图片
- **DLNA 投送** - 投送到支持 DLNA 的音响设备

---

## 快速开始

### 1. 配置音乐库

1. 登录 NAS-OS Web 界面
2. 进入「应用中心」→「Audio Station」
3. 点击「设置」→「音乐库路径」
4. 选择包含音乐文件的目录（支持多个目录）
5. 点击「扫描」，等待索引完成

### 2. 播放音乐

- 浏览专辑/艺术家/文件夹视图
- 点击任意歌曲即可开始播放
- 支持队列管理：下一首播放、添加到队列

### 3. 创建播放列表

1. 点击左侧「播放列表」→「新建」
2. 输入播放列表名称
3. 拖拽歌曲到播放列表
4. 支持从现有播放列表复制

## 支持格式

| 格式 | 编码 | 采样率支持 |
|------|------|-----------|
| MP3 | MPEG-1/2 Layer 3 | 8-48kHz |
| FLAC | 无损压缩 | 最高 384kHz/32bit |
| AAC | AAC-LC/HE | 8-96kHz |
| OGG | Vorbis/Opus | 8-192kHz |
| WAV | PCM | 最高 384kHz/32bit |
| APE | Monkey's Audio | 最高 192kHz |
| DSD | DSD64/128/256 | 2.8/5.6/11.2MHz |

## DLNA 投送

### 发现设备

Audio Station 会自动发现局域网内支持 DLNA/UPnP 的设备。

### 投送步骤

1. 播放音乐时，点击播放器右下角「投送」图标
2. 选择目标设备
3. 音乐将在目标设备播放，手机/浏览器变为遥控器

## 移动端访问

### 方式一：浏览器访问

直接在手机浏览器中访问 NAS-OS Web 界面，Audio Station 自适应移动端。

### 方式二：WebDAV 同步

1. 在设置中启用 WebDAV 音乐同步
2. 使用支持 WebDAV 的音乐播放器连接
3. 可离线缓存播放列表

## 音质优化

### 转码设置

- **原始格式** - 不转码，直接播放（需客户端支持）
- **自动转码** - 根据客户端能力自动选择最佳格式
- **指定格式** - 强制转码为指定格式（如 FLAC→MP3 节省带宽）

### 均衡器

内置 10 段均衡器，支持：
- 预设模式（流行、摇滚、古典、爵士等）
- 自定义 EQ 曲线
- 独立低音/高音调节

## 常见问题

### Q: 扫描后部分歌曲未显示？

检查：
1. 文件格式是否在支持列表中
2. 文件是否损坏（尝试用其他播放器打开）
3. 文件名编码是否正确

### Q: DLNA 设备搜索不到？

确认：
1. 设备与 NAS 在同一局域网
2. 设备的 DLNA 功能已开启
3. 防火墙未阻断 UPnP 端口（1900/UDP）

### Q: 高码率音乐播放卡顿？

解决方案：
1. 启用转码降低码率
2. 检查网络带宽（建议有线连接）
3. 减少同时播放设备数
