# 整机备份与灾难恢复使用指南

> **版本**: v2.481.0  
> **更新日期**: 2026-05-02

---

## 概述

NAS-OS 整机备份系统提供完整的系统级备份与恢复能力，包括整机快照、增量备份、灾难恢复演练等功能。

### 主要功能

- **整机快照** - 一键备份系统配置、用户数据、应用状态
- **增量备份** - 仅备份变更数据，节省存储空间
- **异地备份** - 支持远程 NAS、云存储作为备份目标
- **灾难恢复演练** - 定期验证备份可恢复性
- **定时调度** - 自动执行备份计划

---

## 整机备份

### 创建备份

1. 进入「备份」→「整机备份」
2. 点击「新建备份」
3. 选择备份内容：
   - 系统配置（必选）
   - 用户数据（可选目录）
   - 应用数据（已安装应用）
   - Docker 容器及数据
4. 选择备份目标：
   - 本地存储池
   - 外接 USB 磁盘
   - 远程 NAS
   - 云存储（S3/OSS/B2）
5. 设置备份策略：
   - **全量备份** - 完整备份所有数据
   - **增量备份** - 仅备份自上次备份后的变更
6. 点击「开始备份」

### 备份调度

```yaml
# 示例：每日增量 + 每周全量
backup_schedule:
  incremental:
    frequency: daily
    time: "03:00"
  full:
    frequency: weekly
    day: sunday
    time: "02:00"
  retention:
    daily: 7        # 保留7天的每日备份
    weekly: 4       # 保留4周的全量备份
    monthly: 3      # 保留3个月的月度备份
```

### 备份加密

支持 AES-256 加密备份数据：
1. 在备份设置中启用加密
2. 设置加密密码（务必牢记，恢复时需要）
3. 可选导出密钥文件到安全位置

## 灾难恢复

### 恢复步骤

1. 启动 NAS-OS 恢复环境（USB 启动盘）
2. 选择备份源
3. 选择恢复点（时间线视图）
4. 选择恢复内容：
   - 完整恢复（整机还原）
   - 选择性恢复（指定目录/应用）
5. 确认恢复目标磁盘
6. 开始恢复

### 恢复演练

定期验证备份有效性：

1. 进入「备份」→「恢复演练」
2. 点击「创建演练」
3. 系统自动：
   - 选择最近的备份点
   - 在隔离环境中模拟恢复
   - 验证数据完整性
   - 生成演练报告
4. 查看演练结果和通过状态

建议频率：每月至少一次恢复演练。

## 备份监控

### 健康检查

系统自动监控：
- 备份任务执行状态
- 备份目标空间使用率
- 备份数据完整性校验
- 备份失败告警

### 告警配置

| 告警类型 | 触发条件 | 通知方式 |
|----------|---------|----------|
| 备份失败 | 任务执行失败 | 邮件/Webhook |
| 空间不足 | 目标空间 <20% | 邮件/站内通知 |
| 完整性异常 | 校验不通过 | 邮件/紧急通知 |
| 长时间未备份 | 超过计划时间 48h | 邮件/站内通知 |

## 最佳实践

1. **3-2-1 原则** - 3 份副本、2 种介质、1 份异地
2. **定期演练** - 备份不演练等于没备份
3. **加密备份** - 敏感数据务必加密
4. **监控告警** - 确保备份失败能及时发现
5. **文档化恢复流程** - 记录恢复步骤，紧急时可快速操作
