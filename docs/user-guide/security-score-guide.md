# 安全评分 (Security Score) 用户指南

> **适用版本**: v2.485.0+ | **模块路径**: `internal/securityscore/`

## 概述

安全评分模块提供系统安全态势的综合评估，通过多维度安全检查生成 0-100 的评分和 A-F 等级，帮助用户快速了解系统安全状态并获取改进建议。

## 功能特性

- **多分类加权评分**: 网络/存储/认证/加密/备份等多个安全维度
- **五级评分体系**: A(90+)/B(80+)/C(70+)/D(60+)/F(60以下)
- **安全检查注册与执行**: 支持 pass/fail/warning 三态检查
- **评分历史记录**: 追踪安全评分变化趋势
- **智能改进建议**: 按优先级(high/medium/low)排序的安全加固建议

## API 端点

### 获取当前评分

```
GET /api/v1/security/score
```

响应示例:
```json
{
  "code": 200,
  "data": {
    "overall": 85.5,
    "grade": "B",
    "categories": {
      "network": {"name": "网络", "score": 90.0, "weight": 0.25},
      "storage": {"name": "存储", "score": 80.0, "weight": 0.25},
      "auth": {"name": "认证", "score": 88.0, "weight": 0.20},
      "encryption": {"name": "加密", "score": 75.0, "weight": 0.15},
      "backup": {"name": "备份", "score": 92.0, "weight": 0.15}
    },
    "last_updated": "2026-05-06T20:00:00Z"
  }
}
```

### 执行全部安全检查

```
POST /api/v1/security/checks/run
```

### 获取检查详情

```
GET /api/v1/security/checks/{id}
```

### 获取评分历史

```
GET /api/v1/security/history
```

### 获取改进建议

```
GET /api/v1/security/recommendations
```

响应示例:
```json
{
  "code": 200,
  "data": [
    {
      "id": "rec-001",
      "category": "encryption",
      "title": "启用全卷加密",
      "description": "建议对敏感数据存储池启用 LUKS 全卷加密",
      "priority": "high",
      "impact": "防止物理设备泄露"
    }
  ]
}
```

## 评分等级说明

| 等级 | 分数范围 | 安全状态 | 建议操作 |
|------|----------|----------|----------|
| **A** | 90-100 | 优秀 | 定期检查，保持现状 |
| **B** | 80-89 | 良好 | 关注中优先级建议 |
| **C** | 70-79 | 一般 | 需要改善，优先处理高优先级项 |
| **D** | 60-69 | 较差 | 立即处理安全建议 |
| **F** | 0-59 | 危险 | 紧急加固，存在严重安全隐患 |

## 检查类别

| 类别 | 检查内容 |
|------|----------|
| 网络 | 防火墙规则/端口暴露/VPN配置/TLS证书 |
| 存储 | RAID状态/磁盘健康/快照策略/加密状态 |
| 认证 | MFA启用/密码策略/会话管理/ACL配置 |
| 加密 | 传输加密/存储加密/密钥管理/证书有效期 |
| 备份 | 备份频率/异地备份/恢复测试/不可变备份 |

## 使用场景

- **日常巡检**: 每日查看安全评分，及时发现安全退化
- **合规审计**: 生成安全评分报告，满足合规要求
- **安全加固**: 根据改进建议逐步提升系统安全性
- **事件响应**: 安全事件后评估系统安全状态恢复情况
