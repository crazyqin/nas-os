## 🖥️ NAS-OS - 让存储更智能

**免费开源家用NAS系统，三大独家功能领先行业**

---

### 🏆 三大独家功能

#### 🔒 WriteOnce - 防勒索最后一道防线

**竞品均无，业界首发**

- 不可变存储（WORM），数据写入后无法篡改
- 勒索病毒攻击？快照一键还原
- 合规归档需求？自动锁定满足法规
- **群晖、飞牛、TrueNAS都没有，只有我们有**

**适用场景**：企业财务数据、医疗病历、法律文档、个人珍贵照片

---

#### 📊 Fusion Pool - 存存分离，省钱又快

**智能分层存储，TrueNAS没有**

- 热数据放SSD，秒速响应
- 冷数据归HDD，大容量省钱
- 自动识别访问频率，智能迁移
- **不用手动分盘，系统自动帮你省钱**

**对比群晖Tiering**：群晖只支持简单分层，Fusion Pool支持：
- 多级缓存（SSD→NVMe→HDD）
- 访问频率智能分析
- 自定义分层策略
- 云存储冷归档

---

#### 🤖 AI相册 - 说搜就搜，本地推理

**以文搜图，领先飞牛fnOS**

- 输入"去年夏天的海边照片"，秒级定位
- CLIP模型本地推理，隐私不入云端
- 人脸识别 + 场景分类 + 时间聚类
- **不用一张张翻，像聊天一样搜照片**

**对比竞品**：
- 飞牛fnOS：人脸识别，无语义搜索
- 群晖DSM：人脸识别，无语义搜索
- TrueNAS：无AI相册功能

### 🚀 立即开始

```bash
# Docker一键部署
docker pull ghcr.io/crazyqin/nas-os:v2.255.0
docker run -d --name nasd -p 8080:8080 \
  -v /data:/data -v /etc/nas-os:/config \
  ghcr.io/crazyqin/nas-os:v2.255.0

# 访问 http://localhost:8080
# 默认账号: admin / admin123
```
