# Presto 高速文件传输 - 用户界面设计文档

## 1. 概述

### 1.1 项目背景
Presto 高速文件传输功能对标群晖 Presto File Server，为 NAS-OS 提供高性能文件传输能力。本设计文档定义了 Presto 功能的用户界面规范、交互设计和前端组件实现方案。

### 1.2 设计目标
- **直观性**：用户一眼就能了解传输状态和进度
- **高效性**：支持批量操作和快速配置
- **美观性**：遵循 NAS-OS 设计系统，保持一致的视觉风格
- **响应式**：完美适配桌面端和移动端

### 1.3 核心功能
1. **传输任务管理**：创建、暂停、恢复、取消传输任务
2. **实时进度监控**：传输速度、进度、剩余时间
3. **传输历史记录**：查看历史传输记录和统计
4. **配置管理**：传输参数配置（压缩、加密、并发数等）
5. **性能基准测试**：磁盘性能测试（对标 Presto Benchmark）

#### 2.2.3 已传输数据
- **图标**：📊 图表图标
- **渐变色**：橙色渐变 (#F59E0B → #D97706)

- **图标**：✅ 勾选图标

### 2.5 配置面板

#### 2.5.1 传输配置
```
┌─────────────────────────────────────────────────────────────┐
│  传输配置                                                     │
├─────────────────────────────────────────────────────────────┤
│  最大并发数: [滑块] 4                                           │
│  压缩级别: [下拉选择] 6 (平衡)                                  │
│  分块大小: [下拉选择] 64 MB                                     │
│  带宽限制: [输入框] 0 (不限) MB/s                                │
│  ☑ 启用 AES 加密                                              │
└─────────────────────────────────────────────────────────────┘
```

#### 2.5.2 配置说明
- **最大并发数**：1-8，默认4
- **压缩级别**：0-9，0=不压缩，9=最大压缩
- **分块大小**：16/32/64/128/256 MB
- **带宽限制**：0=不限速，或指定 MB/s
- **AES加密**：默认启用

## 3. 用户体验（UX）规范

### 3.1 交互原则

#### 3.1.1 即时反馈
- 用户操作后立即显示视觉反馈
- 使用 Toast 通知显示操作结果
- 长时间操作显示加载状态

#### 3.1.2 状态可见性
- 传输状态实时更新（WebSocket）
- 进度条动画流畅
- 速度数据每秒更新

#### 3.1.3 错误处理
- 清晰的错误提示信息
- 提供重试操作
- 错误日志可查看

#### 3.1.4 操作确认
- 危险操作（取消/删除）需要确认
- 使用模态对话框确认
- 提供撤销操作（5秒内）

### 3.2 动画规范

#### 3.2.1 页面过渡
- **时长**：300ms
- **缓动**：ease-out
- **效果**：淡入淡出

#### 3.2.2 进度动画
- **进度条**：平滑过渡，100ms
- **数字滚动**：使用计数动画
- **脉冲效果**：2s无限循环

#### 3.2.3 状态变化
- **颜色过渡**：200ms
- **大小变化**：150ms
- **图标旋转**：持续旋转

### 3.3 响应式设计

#### 3.3.1 桌面端（≥1024px）
- 双栏布局：任务列表 + 详情面板
- 完整表格显示
- 图表全尺寸显示

#### 3.3.2 平板端（768px-1023px）
- 单栏布局，详情面板折叠
- 表格可横向滚动
- 图表自适应宽度

#### 3.3.3 移动端（<768px）
- 完全单栏布局
- 卡片式任务列表
- 简化的详情视图
- 底部操作栏

### 3.4 无障碍设计

#### 3.4.1 键盘导航
- 支持 Tab 键导航
- 快捷键支持：
  - `Ctrl+N`：新建传输
  - `Space`：暂停/恢复
  - `Delete`：取消任务

#### 3.4.2 屏幕阅读器
- 语义化 HTML 标签
- ARIA 标签
- 进度状态播报

## 4. 前端组件设计

### 4.1 技术栈
- **HTML5**：语义化标签
- **CSS3**：CSS 变量、Flexbox、Grid
- **JavaScript**：原生 JS，无框架依赖
- **图表库**：ECharts 5.x
- **图标**：SVG 内联图标

### 4.2 组件结构

#### 4.2.1 页面组件
```html
<presto-page>
  <presto-header />
  <presto-stats />
  <presto-content>
    <presto-task-list />
    <presto-task-detail />
  </presto-content>
  <presto-history />
</presto-page>
```

#### 4.2.2 组件列表
1. **PrestoHeader**：页面头部
2. **PrestoStats**：统计卡片区域
3. **PrestoTaskList**：任务列表
4. **PrestoTaskItem**：单个任务项
5. **PrestoTaskDetail**：任务详情面板
6. **PrestoSpeedChart**：速度图表
7. **PrestoProgressRing**：圆形进度环
8. **PrestoHistoryTable**：历史记录表格
9. **PrestoConfigPanel**：配置面板
10. **PrestoBenchmarkTest**：性能测试组件

### 4.3 数据接口

#### 4.3.1 API 端点
```
GET    /api/v1/presto/transfers          # 获取传输列表
POST   /api/v1/presto/transfers          # 创建传输任务
GET    /api/v1/presto/transfers/:id      # 获取传输详情
PUT    /api/v1/presto/transfers/:id      # 更新传输（暂停/恢复）
DELETE /api/v1/presto/transfers/:id      # 删除传输
GET    /api/v1/presto/stats              # 获取统计信息
GET    /api/v1/presto/config             # 获取配置
PUT    /api/v1/presto/config             # 更新配置
POST   /api/v1/presto/benchmark          # 启动性能测试
GET    /api/v1/presto/benchmark/:id      # 获取测试结果
```

#### 4.3.2 WebSocket 消息
```json
{
  "type": "presto:transfer:progress",
  "payload": {
    "id": "xfer-123",
    "transferred": 1073741824,
    "total": 2147483648,
    "speed": 131072000,
    "progress": 50.0
  }
}
```

### 4.4 状态管理

#### 4.4.1 应用状态
```javascript
const PrestoState = {
  transfers: [],           // 传输任务列表

```

## 6. 性能优化

### 6.1 加载优化
- **骨架屏**：页面加载时显示骨架屏
- **懒加载**：图表和历史记录延迟加载
- **虚拟滚动**：大量任务时使用虚拟滚动

### 6.2 渲染优化
- **requestAnimationFrame**：进度更新使用 RAF
- **防抖/节流**：频繁更新使用节流
- **DOM 缓存**：缓存常用 DOM 元素

### 6.3 数据优化
- **增量更新**：WebSocket 增量更新进度
- **本地缓存**：配置和历史记录本地缓存
- **分页加载**：历史记录分页加载
