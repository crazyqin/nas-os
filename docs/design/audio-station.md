## 1. 群晖 Audio Station 简介

Synology Audio Station 是群晖的音乐管理套件，提供：
- 音乐库管理（专辑/艺术家/播放列表）
- 多格式支持（MP3/FLAC/AAC等）
- 在线播放和电台
- 移动端同步
- DLNA投送

## 6. API设计

| API | 说明 | Method |
|-----|------|--------|
| /api/v1/music/library | 音乐库信息 | GET |
| /api/v1/music/albums | 专辑列表 | GET |
| /api/v1/music/artists | 艺术家列表 | GET |
| /api/v1/music/songs | 歌曲列表 | GET |
| /api/v1/music/songs/:id/stream | 流媒体播放 | GET |
| /api/v1/music/playlists | 播放列表 | GET/POST |
| /api/v1/music/playlists/:id/songs | 列表歌曲 | GET/POST |
| /api/v1/music/search | 音乐搜索 | GET |
| /api/v1/music/dlna/devices | DLNA设备 | GET |
