## 1. 群晖 Presto 简介

Synology Presto 是群晖 DSM 7.3 的传输加速套件，通过多通道传输、智能缓存、压缩等技术大幅提升文件传输效率。

### 1.1 核心特性

| 特性 | 说明 |
|------|------|
| 多通道传输 | 同时使用多个TCP连接 |
| 智能缓存 | 内存缓存热数据 |
| 压缩传输 | 实时压缩减少带宽 |
| 增量同步 | 只传输变化部分 |
| 断点续传 | 支持中断恢复 |

### 1.2 性能提升
- 官方宣称：传输速度提升 3-5倍
- 适用场景：大文件传输、跨网络同步

## 2. nas-os 对标方案

### 2.1 技术对比

| 功能 | Presto实现 | nas-os现状 | 对标方案 |
|------|-----------|------------|----------|
| 多通道传输 | 多TCP并发 | 单连接 | SMB Multichannel开发 |
| 智能缓存 | 内存缓存池 | LRU缓存 | 扩展至传输层 |
| 压缩传输 | 实时压缩 | 存储压缩 | 网络层压缩 |
| 增量同步 | rsync算法 | ✅已有 | 保持优势 |
| 断点续传 | 会话保持 | ✅已有 | 保持优势 |

### 2.2 nas-os 已有优势
- **WriteOnce不可变存储**: Presto无此功能
- **多云挂载**: 6+平台透明读写
- **本地LLM**: 数据不出域智能处理

### 3.2 核心组件

#### 3.2.1 多通道传输器（MultichannelManager）
- 功能：建立多个并发传输通道
- 协议：SMB Multichannel、HTTP多连接
- 状态：已有设计文档，需开发实现

#### 3.2.2 传输缓存（TransferCache）
- 功能：内存缓存活跃传输数据
- 算法：LRU + 预读优化
- 配置：可调缓存大小

#### 3.2.3 压缩引擎（CompressEngine）
- 功能：实时压缩传输数据
- 算法：zstd/lz4快速压缩
- 选择：根据数据类型自动选择

#### 3.2.4 增量引擎（DeltaEngine）
- 功能：只传输变化部分
- 算法：rsync rolling checksum
- 状态：✅ 已实现

## 4. 性能目标

### 4.1 基准对比

| 场景 | 单通道 | 多通道 | 提升 |
|------|--------|--------|------|
| 大文件(10GB) | 100MB/s | 350MB/s | 3.5x |
| 多小文件(10000) | 50MB/s | 180MB/s | 3.6x |
| 跨网传输 | 受限带宽 | 充分利用 | 2-3x |

### 4.2 系统要求
- 多网卡环境效果最佳
- 内存充足（缓存需求）
- CPU支持压缩（可选）
