## 1. 设计理念

### 核心原则

| 原则 | 说明 | 飞牛fnOS借鉴 |
|------|------|-------------|
| **简洁** | 每步只做一件事，界面留白充足 | fnOS全屏引导页，无多余元素 |
| **引导式** | 推荐选项前置，高级选项折叠 | fnOS默认推荐RAID，一键完成 |
| **零门槛** | 非技术用户3分钟内完成初始化 | fnOS语言→网络→存储→账号四步完成 |

### 设计目标

- **首次体验时间**: ≤ 5分钟（普通用户）
- **步骤数**: 6步（可跳过高级配置）
- **默认值覆盖率**: ≥ 80%（推荐选项即最优选项）
- **移动端适配**: 100%响应式，手机可完成全部配置
- **错误率**: ≤ 2%（清晰的错误提示和实时校验）

### Step 3: 存储池创建

**页面布局**:
```
┌─────────────────────────────────────────┐
│                                         │
│     💾 存储池创建                        │
│                                         │
│     ┌─────────────────────────────┐     │
│     │  检测到的磁盘               │     │
│     │                             │     │
│     │  /dev/sda  4TB  WD Red  ✅  │     │
│     │  /dev/sdb  4TB  WD Red  ✅  │     │
│     │  /dev/sdc  4TB  WD Red  ✅  │     │
│     │  /dev/nvme0n1 512GB  ✅     │     │
│     └─────────────────────────────┘     │
│                                         │
│     RAID类型选择:                       │
│                                         │
│     ┌──────┐ ┌──────┐ ┌──────┐         │
│     │RAID 1│ │RAID 5│ │RAID 6│         │
│     │镜像  │ │推荐✓ │ │双校验│         │
│     └──────┘ └──────┘ └──────┘         │
│                                         │
│     存储池名: [storage_pool_1  ]        │
│     文件系统: btrfs (推荐)              │
│                                         │
│     预计可用空间: 8TB                    │
│     数据保护: 单盘故障容错              │
│                                         │
│     [← 上一步]  [下一步 →]              │
└─────────────────────────────────────────┘
```

**交互逻辑**:
- 自动检测磁盘，显示型号、容量、健康状态
- 根据磁盘数量智能推荐RAID类型：
  - 1盘 → Basic/JBOD
  - 2盘 → RAID 1（镜像）
  - 3盘+ → RAID 5（推荐）
  - 4盘+ → RAID 6（高安全）
- RAID 5 为默认推荐（3盘以上场景）
- SSD自动识别，可选作为缓存层（Fusion Pool）
- 显示预估可用空间和故障容错能力
- 高级选项折叠：自定义RAID、加密、配额

**API**:
```
GET  /api/v1/setup/storage/disks          # 获取磁盘列表
POST /api/v1/setup/storage/pool           # 创建存储池
Body: {
  "name": "storage_pool_1",
  "raid_level": "raid5",
  "disks": ["/dev/sda", "/dev/sdb", "/dev/sdc"],
  "filesystem": "btrfs",
  "encryption": false
}
```

## 5. 技术实现方案

### 5.1 前端架构

```
web/src/
├── setup/
│   ├── SetupWizard.tsx          # 主容器（路由+状态管理）
│   ├── SetupWizard.css          # 全局样式
│   ├── components/
│   │   ├── StepIndicator.tsx    # 进度指示器
│   │   ├── StepNav.tsx          # 上一步/下一步按钮
│   │   ├── LanguageSelect.tsx   # Step1 语言选择
│   │   ├── NetworkConfig.tsx    # Step2 网络配置
│   │   ├── StoragePool.tsx      # Step3 存储池创建
│   │   ├── AdminAccount.tsx     # Step4 管理员账号
│   │   ├── ServiceConfig.tsx    # Step5 基础服务
│   │   └── SetupComplete.tsx    # Step6 完成页面
│   ├── hooks/
│   │   ├── useSetupState.ts     # 向导状态管理
│   │   └── useSetupAPI.ts       # API调用封装
│   └── types/
│       └── setup.ts             # TypeScript类型定义
```

**技术栈**:
- React 18 + TypeScript
- Zustand 状态管理
- React Router v6 步骤路由
- CSS Modules 样式隔离
- Axios API请求

### 5.2 后端 API

```
internal/setup/
├── handler.go          # HTTP处理器
├── service.go          # 业务逻辑
├── types.go            # 数据类型
├── network.go          # 网络检测/配置
├── storage.go          # 磁盘检测/池创建
└── middleware.go        # 安装状态中间件
```

**API 路由**:

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/setup/status` | 检查是否已安装 |
| POST | `/api/v1/setup/locale` | 设置语言 |
| GET | `/api/v1/setup/network/interfaces` | 获取网络接口 |
| POST | `/api/v1/setup/network/configure` | 配置网络 |
| GET | `/api/v1/setup/storage/disks` | 获取磁盘列表 |
| POST | `/api/v1/setup/storage/pool` | 创建存储池 |
| POST | `/api/v1/setup/admin` | 创建管理员 |
| POST | `/api/v1/setup/services` | 配置基础服务 |
| POST | `/api/v1/setup/complete` | 完成安装 |

### 5.3 安装状态管理

```go
// 安装状态持久化
type SetupState struct {
    Status      string    `json:"status"`       // not_started/in_progress/completed
    CurrentStep int       `json:"current_step"`  // 1-6
    Locale      string    `json:"locale"`
    StartedAt   time.Time `json:"started_at"`
    CompletedAt time.Time `json:"completed_at"`
}
```

- 安装状态存储在 `/etc/nas-os/setup.json`
- 已安装时访问 `/setup` 自动跳转到控制面板
- 支持断点续传（刷新页面后恢复到当前步骤）

### 5.4 安全设计

- 安装完成后禁用安装API
- 管理员密码使用 bcrypt 加密存储
- 安装过程全程 HTTPS（自签名证书）
- CSRF Token 保护所有写操作
