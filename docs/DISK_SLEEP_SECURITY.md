# 磁盘休眠安全审计报告

## 概述

本文档评估NAS-OS按需唤醒硬盘功能的安全风险，并提供配置最佳实践建议。

---

## 1. 安全风险分析

### 1.1 RAID状态一致性风险

| 风险等级 | 场景 | 影响 | 建议 |
|---------|------|------|------|
| **高** | RAID重建期间 | 休眠可能导致重建中断，数据丢失 | **禁止休眠** |
| **高** | RAID同步期间 | 同步延迟，阵列降级 | **禁止休眠** |
| **中** | 正常RAID运行 | 唤醒延迟不影响一致性 | 允许休眠 |
| **低** | 单盘运行 | 无RAID依赖 | 允许休眠 |

**安全配置**:
```json
{
  "exclude_disks": ["磁盘正在重建的设备"],
  "raid_check_before_sleep": true
}
```

### 1.2 唤醒延迟风险

| 场景 | 延迟时间 | 影响 |
|------|---------|------|
| SMB/NFS访问 | 5-15秒 | 客户端可能超时重试 |
| Web界面访问 | 5-15秒 | 用户感知延迟 |
| 定时任务 | 5-15秒 | 任务可能延迟执行 |
| 快照备份 | 10-30秒 | 备份窗口延长 |

**缓解措施**:
- 设置合理的超时时间（建议≥30秒）
- 在备份时段设置例外时间范围
- 关键任务前手动唤醒

### 1.3 SMART监控中断风险

| 风险 | 说明 | 缓解措施 |
|------|------|----------|
| 监控数据缺失 | 休眠期间无法采集SMART数据 | 在唤醒后立即采集 |
| 健康预警延迟 | 问题发现延迟 | 定期强制唤醒检查 |
| 预测失效 | 寿命预测不准确 | 标记休眠时段数据缺失 |

**推荐配置**:
```json
{
  "smart_check_interval_hours": 6,
  "smart_check_wake_disks": true,
  "smart_after_wake_delay_seconds": 30
}
```

### 1.4 数据完整性风险

| 风险等级 | 场景 | 说明 |
|---------|------|------|
| **高** | 写入时强制休眠 | 数据未完全写入，可能损坏 |
| **中** | 缓存未刷写 | 内存缓存数据丢失 |
| **低** | 正常休眠 | 系统正常处理，影响小 |

**安全措施**:
- 仅在空闲状态休眠
- 休眠前刷写缓存
- 禁止写入时休眠

## 2. 配置最佳实践

### 2.1 推荐配置参数

```yaml
disk_sleep:
  enabled: true
  idle_timeout_minutes: 30   # 30分钟空闲后休眠
  
  exclude_disks:
    - "/dev/sda"             # 系统盘不休眠
    - "/dev/sdb"             # 热数据盘不休眠
  
  exception_time_ranges:
    - start_hour: 2          # 备份时段不休眠
      end_hour: 4
    - start_hour: 22         # 晚间使用高峰不休眠
      end_hour: 23
  
  safety_settings:
    raid_check_before_sleep: true     # 检查RAID状态
    flush_cache_before_sleep: true    # 刷写缓存
    smart_check_after_wake: true      # 唤醒后SMART检查
```

### 2.2 适合休眠的场景

| 场景 | 推荐配置 | 说明 |
|------|---------|------|
| 家庭存储 | 空闲30分钟休眠 | 节省电费，噪音降低 |
| 冷数据归档 | 空闲15分钟休眠 | 数据访问频率低 |
| 夜间待机 | 例外时段22:00-08:00 | 夜间使用少 |

### 2.3 不适合休眠的场景

| 场景 | 原因 | 建议 |
|------|------|------|
| 热数据盘 | 频繁访问，唤醒成本高 | 排除休眠 |
| RAID重建 | 数据完整性风险 | 禁止休眠 |
| 24/7服务 | 响应时间要求高 | 排除休眠 |
| 系统盘 | 系统稳定性依赖 | 排除休眠 |
| SSD/NVMe | 无机械部件，休眠无益 | 排除休眠 |

## 3. 风险等级评估表

| 磁盘类型 | RAID状态 | 数据类型 | 休眠风险等级 | 建议 |
|---------|---------|---------|-------------|------|
| HDD | 单盘 | 冷数据 | 低 | **推荐休眠** |
| HDD | 单盘 | 热数据 | 中 | 评估后决定 |
| HDD | RAID正常 | 冷数据 | 低 | 推荐休眠 |
| HDD | RAID正常 | 热数据 | 中 | 排除休眠 |
| HDD | RAID重建 | 任何 | **高** | **禁止休眠** |
| SSD | 任何 | 任何 | 无意义 | 排除休眠 |
| NVMe | 任何 | 任何 | 无意义 | 排除休眠 |

## 4. 监控与告警

### 4.1 建议监控指标

- 休眠次数/频率
- 平均休眠时长
- 唤醒次数/延迟
- 休眠期间的访问失败
- SMART数据完整性

### 4.2 建议告警规则

| 告警 | 条件 | 级别 |
|------|------|------|
| 休眠失败 | 连续3次休眠失败 | 警告 |
| 唤醒延迟过长 | 唤醒>30秒 | 警告 |
| RAID状态异常休眠 | RAID降级时尝试休眠 | 严重 |
| SMART数据缺失 | >6小时未采集 | 警告 |

---

## 5. 总结

按需唤醒硬盘功能可以显著节省能耗，但需要谨慎配置：

**安全原则**:
1. 系统盘和热数据盘不休眠
2. RAID异常时禁止休眠
3. 备份时段设置例外
4. 休眠前确保数据完整性

**推荐策略**:
- 家庭NAS: 冷数据盘休眠30分钟空闲
- 企业NAS: 仅归档盘休眠，配置例外时段
- 监控: 关注唤醒延迟和SMART数据完整性
